허브에 연결

허브형(ieun)을 쓸 때 이 PC를 허브에 연결합니다. 허브 화면의 "PC 연결 링크"를 이 PC에서 열면 가장 쉬워요. 직접 하려면 허브 주소를 넣고 "연결"을 누르면 6자리 코드가 나오고, 허브 설정 → 밖에서도 쓰기에서 같은 코드를 승인하면 끝납니다.
