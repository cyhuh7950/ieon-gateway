이어온 개인정보 처리방침

시행일 2026-11-19(2026-11-14 처음) · 적용 대상: 이어온 앱(안드로이드·PC)과 이어온 웹 화면, 다른 사람의 허브에 가입해 쓰는 경우

1. 이어온은 어떻게 동작하나요

이어온은 사용자 자신이 설치한 이어온 서버(내 PC 또는 내 허브)에 연결해, 그 서버와 이어진 내 AI 작업 세션(Codex·Claude Code 등)과 대화하게 해 주는 앱입니다. 질문과 답은 사용자가 연결한 그 서버에만 저장되며, 이어온 앱 개발자에게 보내지지 않습니다. 이어온에는 광고·이용 분석 기능이 없습니다. 다른 사람이 운영하는 이어온 허브에 가입해 쓰는 경우, 그 허브의 운영자(허브 주인)가 아래 가입 정보를 관리합니다.

2. 다루는 정보

정보어디에 있나요왜 필요한가요
서버 주소, 기기 열쇠내 기기 안(앱 전용 저장소). 서버에는 열쇠를 알아볼 수 없게 바꾼 값(해시)만내 서버에 연결하기 위해
기기 이름, 마지막 사용 시각내 서버웹 화면의 "연결된 앱" 목록에서 알아보고 끊을 수 있게
질문과 답, 허락(승인) 기록내 서버(승인 기록은 180일 보관)대화를 이어 보고, 허락 여부를 남기기 위해
음성저장하지 않음말로 쓰기·읽어 주기는 기기에 들어 있는 기능을 씁니다. 기기에 따라 음성이 기기 회사(구글·마이크로소프트·애플) 서버를 거칠 수 있습니다. 받아쓴 글은 사용자가 보내기를 누를 때만 질문으로 보내집니다.
가입 정보(다른 사람의 허브에 가입한 경우): 이메일, 비밀번호를 알아볼 수 없게 바꾼 값(해시), 가입·승인 상태, 약관에 동의한 때, 오늘 보낸 질문 수그 허브로그인하고, 허브 주인이 가입을 승인·관리하고, 하루 질문 한도를 지키기 위해. 허브 주인은 이메일·상태·PC 수·질문 수만 보며 대화 내용은 화면에서 볼 수 없습니다. 메일은 보내지 않습니다.
알림 주소(휴대폰 알림을 켠 경우)내 서버"○○가 답했어요" 알림을 보내기 위해. 알림은 구글(Firebase)·브라우저 알림 서버를 거치므로 질문·답 내용은 넣지 않고 AI 직원 이름과 정해진 말만 보냅니다.

다른 사람이 운영하는 허브에는 만 14세 미만은 가입할 수 없습니다. 그 허브의 관리자는 가입자의 대화 내용을 화면으로 볼 수 없지만, 서버의 데이터 파일에는 기술적으로 접근할 수 있습니다.

3. 다른 곳에 주는 정보

이어온 앱 개발자는 위 정보를 받거나 다른 곳에 팔거나 넘기지 않습니다. 위 표에 적은 기기 회사의 음성 기능·알림 서버를 거치는 것만 있습니다. 내 서버와 이어진 AI 작업 세션(Codex·Claude Code 등)에는 사용자가 보낸 질문이 그 서비스의 약관에 따라 전달됩니다.

4. 앱이 쓰는 권한

인터넷(내 서버에 연결)과 알림만 씁니다. 안드로이드 앱은 마이크 권한을 갖지 않습니다(말로 쓰기는 기기의 받아쓰기 창이 녹음). 위치·연락처·사진·카메라 권한은 쓰지 않습니다.

5. 지우기

  • 이 기기 연결 끊기: 앱 첫 화면 아래 "이 기기 연결 끊기" — 서버에서 이 기기의 열쇠를 지우고 앱에 저장된 연결 정보도 지웁니다. 웹 화면 설정 → 앱과 기기 → 이어온 앱 연결에서도 끊을 수 있습니다.
  • 대화 기록 지우기: 앱 1:1 대화 위쪽 ✎ 또는 웹 화면의 연결 설정 → "이 대화의 서버 보관 기록 지우기" — 서버에 남은 그 대화의 질문·답을 지웁니다(AI 서비스 쪽 세션 기록은 그 서비스에서 관리).
  • 가입 지우기(다른 사람의 허브): 허브 주인에게 계정 삭제를 요청하면 그 허브의 내 가입 정보와 이어온 기록(대화 기록·방·예약·연결한 PC·앱 연결)이 모두 지워집니다. 내 PC의 원래 세션 기록은 남습니다.
  • 보관 기간: 질문·답은 지우거나 계정이 지워질 때까지 서버에 보관하고, 승인 기록과 작업 폴더 기록은 180일 뒤 지웁니다. 서버 관리자가 업데이트 때 만드는 백업본에는 지운 뒤에도 얼마 동안 남을 수 있습니다. 프로그램 기록(로그)에는 질문·답·비밀값을 남기지 않습니다.
  • 모두 지우기: 내 서버(이어온 프로그램)와 그 데이터 폴더를 지우면 모든 정보가 지워집니다. 앱을 지우면 기기 안 정보가 지워집니다.

6. 바뀔 때
