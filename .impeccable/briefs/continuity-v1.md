# 이어온 대화 화면 시안

범위: 명확히 지정된 최소 테스트 웹의 정적 상태 시안. 모드: Operate. 제품 코드·클릭형 기능 구현·외부 연결 없음.
PMO의 기존 폰트·밀도·의미 토큰을 계승한다. 독립 브랜드/마케팅 시안이 아니므로 컨셉 추첨·이미지 생성은 이 좁은 범위에 적용하지 않는다.

## Direction contract

THESIS: 원래 대화를 바꾸지 않고 이어 쓴다는 사실과 현재 실행 가능 상태를 한 화면에서 읽는다. 통계 카드·개발 도구 콘솔 장식은 쓰지 않는다.

OWN-WORLD: PMO의 차분한 회색 바탕·흰 표면·남색 액션·청록 연결 상태를 계승한다. 12px 업무 기본, 대화 14px, 명확한 1px 구분선과 넉넉한 줄간격을 쓴다.

STORY: 허용 대화 선택→SINSAN 연결/사용 상태 확인→질문 입력→접수와 답변 구분. 단절·unknown에는 보내기를 차단한다. 삭제는 서버 기록과 PC 원본을 명확히 구분한다.

FIRST VIEWPORT: 상단 서비스/PC/사용자, 왼쪽 대화 목록, 오른쪽 현재 대화·보관 답변·질문 입력이다. 정적 시안 안내와 상태별 이동은 제품 영역 바깥 상단에 둔다. 모바일은 목록을 상단 좁은 선택 영역으로 재배치한다.

FORM: PMO가 지정한 업무용 대화 작업 화면을 직접 구체화한다. 좁고 정해진 요청이므로 concept-seed는 적용 대상 아님. seed는 생성·선택했다고 주장하지 않는다. 제품 버튼은 정적 시안으로 표시하며 상태 이동 링크만 검토용이다.

FINISH: 검토되지 않고 문서화되지 않은 결과는 미완성이다. 독립 검토·판정·정본 DESIGN·모든 보존 PNG의 생성 근거를 확인한 뒤 제출한다.
