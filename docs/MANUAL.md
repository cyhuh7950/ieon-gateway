## 1부 업무 흐름

### 1장 준비물과 설치

**누구:** 모두(가입자는 1-3만)

이어온은 **이미 쓰고 있는 Codex·Claude Code 작업 대화**에 웹·메신저·앱에서 질문을 넣고 그 대화의 답을 받아 오는 프로그램이에요. 새 대화를 몰래 만들거나 대화를 복사하지 않아요. 필요하면 이어온이 새 세션을 만들 수도 있어요(6장).

#### 1-1. 준비물

| 준비물 | 왜 필요해요 | 없으면 |
| --- | --- | --- |
| Windows 10/11 또는 리눅스 PC | 이어온과 연결부(질문을 가져가 엔진에 넣는 부분)가 이 PC에서 돌아요 | 쓸 수 없어요 |
| Node.js 20 이상 | 이어온 실행 | 설치 스크립트가 알려 줘요 |
| Codex(ChatGPT 구독 로그인) 또는 Claude Code(Pro/Max 구독 또는 API 키) | 실제로 답하는 엔진 | 처음 설정 1단계에 "로그인 필요"로 보여요. 그래도 설치는 계속돼요 |
| (허브형) 공개 서버 1대와 도메인(https 권장) | 밖에서·휴대폰에서·여러 사람이 쓰기, 카카오톡·라인 | PC형으로만 써요(텔레그램·디스코드·슬랙은 PC형도 돼요) |
| (메신저) 텔레그램·디스코드·슬랙 봇 토큰, 카카오 오픈빌더·LINE Developers 계정 | 메신저에서 질문 | 메신저 없이 웹·앱으로 써요 |
| (음성, 선택) OpenAI API 키 | 어느 브라우저에서나 음성 입력, 실시간 음성 대화 | 브라우저 내장 음성(크롬·엣지·사파리)으로 써요 |

#### 1-2. 설치(PC형·허브형)

- **Windows PC:** 이어온 폴더에서 `pwsh scripts/install.ps1` 한 번. 부품 설치·설정·로그온 자동 시작·바탕화면 바로 가기 **이어온**까지 만들어요. 자세한 순서는 [따라 하기 1절](BEGINNER_GUIDE.md).
- **리눅스 PC:** `bash scripts/ieon.sh init` 다음 `bash scripts/ieon.sh start --live`. 화면은 `http://127.0.0.1:28760`.
- **허브(공개 서버):** [따라 하기 8-1](BEGINNER_GUIDE.md)의 설치 명령 한 번. 쓰던 허브가 있으면 **설정 → 관리 → 허브 보안 → 새 서버에 설치 → 설치 명령 만들기**로 만든 명령을 새 서버에 붙여 넣어요.

설치 뒤 할 일: PC형은 2장, 허브는 3장으로 가요.

#### 1-3. 가입자가 준비할 것

허브 관리자가 알려 준 **허브 주소**, 내 이메일, 내 PC(이어온 설치·Codex 로그인). 15장 "가입자 쓰기"로 가요.

### 2장 이 PC에서만 쓰기 시작(처음 설정)

**누구:** PC형 · **쓰는 화면:** [처음 설정](#처음-설정4단계), [왼쪽 목록](#왼쪽-목록)

1. 바탕화면 **이어온**(또는 `http://127.0.0.1:28760`)을 열어요. 연결한 대화가 없으면 처음 설정이 저절로 떠요.
2. "어떻게 쓰실 건가요?"에서 **이 PC에서만**을 눌러요. (허브가 있으면 **내 허브에 연결** → 4장.)
3. "이어온을 시작해요"에서 Codex 줄이 "✓ 준비됨"인지 봐요. "로그인 필요"여도 **계속**을 누를 수 있어요(나중에 Codex에 로그인).
4. "이어 쓸 대화를 고르세요"(10초쯤 걸려요)에서 이어 쓸 Codex 대화를 하나 눌러요. 이게 꼭 해야 하는 유일한 선택이에요.
5. "준비됐어요"에서 **대화 열기**. 메신저·허브는 나중에 해도 돼요(**설정하기** 버튼).

다 하면 왼쪽 목록에 대화가 생기고, 다음에 열 때는 처음 설정이 뜨지 않아요. 다시 보려면 주소 끝에 `/#setup`을 붙여요. **나중에 하기**를 누르면 "이 PC에서만"으로 정해지고 닫혀요.

다음: 7장(질문하기). 대화를 더 잇고 싶으면 5장.

### 3장 허브 만들기와 관리자 로그인

**누구:** 허브 관리자 · **쓰는 화면:** [관리자 만들기](#관리자-만들기), [로그인](#로그인), [허브 보안 탭](#관리--허브-보안)

1. 브라우저로 허브 주소를 열면 "관리자 만들기"가 나와요. 비밀번호(10자 이상)를 두 번 넣고 **만들기**.
   - 두 칸이 다르면 "두 비밀번호가 달라요", 짧으면 "비밀번호는 10자 이상으로 정하세요".
2. 다음부터는 "로그인" 화면에서 **이메일 칸은 비우고** 비밀번호만 넣어 **로그인**해요. 왼쪽 위가 "허브 · 주소 · 관리자"면 성공이에요.
   - 비밀번호를 5번 틀리면 "여러 번 틀려 잠시 잠겼어요"(15분).
3. **설정 → 관리 → 허브 보안 → 보안(허브 접속 제한)**에서 누가 허브에 닿을 수 있는지 정해요. "지금 내 주소"를 보고 **내 주소 추가** → **저장**. 휴대폰·다른 사람이 써야 하면 그 주소도 넣거나 Cloudflare Access·Tailscale 방식을 써요(허용되지 않은 곳에서는 "access denied").
4. 허브 자체에서 새 세션(6장)을 쓰려면 같은 탭 **Codex 로그인(이 허브)**에서 **로그인**.

다음: 4장(PC 연결).

### 4장 PC를 허브에 연결

**누구:** 허브 관리자·가입자(자기 PC) · **쓰는 화면:** [앱과 기기 탭](#내-설정--앱과-기기), PC 화면 [허브 연결](#허브-연결pc-화면)

**가장 쉬운 방법 — PC 연결 링크(시험 확인)**

1. 허브 화면 **설정 → 앱과 기기 → 기기 → PC 연결 링크**를 펼치고 **링크 만들기**. 링크는 10분 동안 한 번만 써요. **복사**.
2. 그 링크를 **연결할 PC에서** 열어요. PC 화면에 "이 PC를 허브에 연결할까요?"와 "연결할 허브: 주소"가 나와요. **내가 만든 링크가 맞을 때만** **연결**(이 PC 이름은 비우면 컴퓨터 이름).
3. "허브에 연결했어요…"가 나오고 "허브 주소 · PC 이름 · 연결됨"으로 바뀌어요. 사용 방식은 저절로 "내 허브에 연결"이 돼요.
4. 허브 화면 **설정 → 앱과 기기 → 기기** 표에 그 PC가 "연결됨"으로 보여요.

**직접 하는 방법 — 6자리 코드**

1. PC 화면 **설정 → 앱과 기기 → 허브 연결 → 허브에 연결**에 허브 주소를 넣고 **연결** → 6자리 코드가 나와요.
2. 허브 화면 **설정 → 앱과 기기 → 기기 → 연결 요청**에서 같은 코드인지 보고 **승인**.

**연결한 뒤 알아 둘 것**

- 허브에 연결된 PC의 화면에는 "이 PC는 허브에 연결돼 있어요" 카드와 **허브 화면 열기**가 나와요. **질문·대화 목록은 허브 화면에서** 해요.
- 다시 연결·연결 끊기·허브 잊기는 PC 화면 **설정 → 앱과 기기 → 허브 연결**.
- 허브 화면에서 그 PC 설정(AI 응답·허용 목록 등)은 **설정 → PC 설정**에서 PC를 골라 바꿔요. PC가 꺼져 있으면 "그 PC가 연결돼 있지 않아요…"가 탭 안에 나오고 칸이 막혀요.

### 5장 대화 연결하기

**누구:** 모두 · **쓰는 화면:** [대화 연결 창](#대화-연결-창), [PC 설정 탭](#내-설정--이-pc--pc-설정)

1. 왼쪽 위 **＋ 대화 연결**.
2. (허브) "PC" 칸에서 내 PC를 골라요. 가입자는 자기 PC만 보여요.
3. "고른 PC에서 최근에 쓴 Codex 대화예요" 목록에서 하나를 눌러요(10초쯤 걸려요).
4. 대화가 바로 열리고 왼쪽 목록(허브는 PC 이름 아래)에 생겨요. 허용 목록 추가까지 한 번에 돼요.

- 목록에 없으면 **고급: 대화 ID 직접 넣기**에 Codex 대화 ID와 목록에 보일 이름을 넣고 **연결**.
- 같은 일을 **설정 → 이 PC(허브는 PC 설정) → 그 PC의 Codex 대화 → 대화 목록 불러오기 → 연결**로도 해요.
- Claude Code 대화·Antigravity·Grok 세션은 관리자가 **설정 → 관리 → 대화 등록 → 세션 직접 등록**에서 등록하고, 실행할 PC의 **설정 → 이 PC → Antigravity·Grok 허용 목록**에 넣어요.

### 6장 새 세션 만들기

**누구:** 모두(관리자가 새 세션 기능을 켜 둔 허브·PC) · **쓰는 화면:** [새 세션 창](#새-세션-만들기-창), [연결 설정](#연결-설정)

이어온이 새 Codex·Claude·Antigravity·Grok 세션과 전용 작업 폴더를 만들어요.

1. 왼쪽 위 **＋ 새 세션**.
2. 엔진, (허브) **어디서**, 이름(영문·숫자·- 2~32자), 권한을 고르고 **만들기**.
   - 허브 관리자는 "허브(글로만 답해요)"와 PC·엔진 칸 중에서, 가입자는 자기 PC 중에서 골라요(켜진 PC가 먼저 골라져 있어요).
   - 권한 "전체(명령 실행·인터넷)"는 관리자가 **설정 → 관리 → 대화 등록 → 새 세션 설정**에서 허락해야 보여요.
3. "새 세션 "이름"을 만들었어요. 첫 질문을 보내면 시작해요." → 목록에 생기고 상태는 "첫 질문 전"이에요.
4. 첫 질문을 보내면 시작돼요(7장).

정리: 30분 쓰지 않으면 "잠듦"(질문하면 깨어나요), 14일 쓰지 않으면 보관함(꺼내야 질문). 지우기는 **연결 설정 → 새 세션 → 삭제**(확인 창). 원래 있던 대화는 잠재우기·삭제가 막혀 있고 "이어온에서 만든 새 세션만…" 안내가 나와요.

### 7장 질문하고 답 받기

**누구:** 모두 · **쓰는 화면:** [대화 머리줄](#대화-머리줄), [메시지·입력줄](#메시지입력줄), [처리할 일 카드](#처리할-일-카드)

1. 왼쪽 목록에서 대화를 골라요. 상태가 "보낼 수 있음"인지 봐요.
2. 아래 입력칸에 질문을 쓰고 **보내기**(Enter, 줄바꿈은 Shift+Enter).
3. "✓ 접수 → 실행 중… → ✓ 완료" 순서로 바뀐 뒤 답 말풍선이 나와요. 멈추려면 **중지**.

- **AI 응답 스위치:** PC 화면 위쪽 "AI 응답 켜짐/꺼짐". 꺼져 있으면 처음 보낼 때 "AI가 이 질문에 답해요" 창에서 **켜고 보내기**. 허브 화면에는 "AI 응답(PC 설정)"으로 보이고, 누르면 바꾸는 곳(**설정 → PC 설정 → 실제 실행·Codex 허용 목록 → 실제 실행 켜기**)을 알려 줘요.
- **Codex 대화는 빠른 응답(기본):** 이어온이 그 대화 전용 Codex를 미리 띄워 두어 답이 몇 초 안에 와요(이어온을 켜고 처음 10초쯤은 준비). 이 동안 **Codex 앱에서 그 대화를 함께 쓰지 마세요.** Codex 앱에서도 같은 대화를 자주 연다면 연결 설정 → 고급에서 **번갈아 쓰기**로 바꾸세요. 번갈아 쓰기는 보낼 때 Codex 앱에서 그 대화를 열어 두면 보내지 않아요(앱은 켜 둬도 되고 그 대화만 닫으면 돼요). 답이 10초 넘게 걸릴 수 있어요.
- 막히면 대화 안에 **카드**가 이유와 버튼을 보여 줘요([카드 표](#카드-표)).
- 결과를 모르는 질문은 "확인이 필요한 질문" 카드로 잠겨요. 원래 세션에서 실행됐는지 보고 **실행됐어요** 또는 **실행되지 않았어요**. 이어온은 절대 저절로 다시 보내지 않아요.

### 8장 작업 모드와 승인

**누구:** 모두(Codex·Antigravity 대화) · **쓰는 화면:** [연결 설정](#연결-설정), [처리할 일 카드](#처리할-일-카드)

평소 질문은 읽기 전용이에요. 파일 수정·명령 실행이 필요하면 그 대화만 작업 모드를 켜요.

1. **연결 설정 → 작업 모드 → 작업 모드 켜기**(확인 창). 머리줄에 "작업 모드" 칩.
   - 작업 폴더가 정해진 대화만 켤 수 있어요(**설정 → 이 PC(허브는 PC 설정) → 실제 실행·Codex 허용 목록**의 작업 폴더).
2. 질문을 보내면 엔진이 파일을 고치거나 명령을 실행하려 할 때마다 "파일을 고쳐도 될까요?"·"명령을 실행해도 될까요?" 카드가 떠요.
3. **허용**(이번 한 번만) 또는 **거부**. 정해진 시간(기본 15분) 안에 답하지 않으면 거부돼요.
4. 허용한 결과(실행 완료·실패·결과 불명)가 같은 카드에 기록돼요.

**사람이 직접 할 일:** **연결 설정 → 사람이 직접 할 일**에서 "모든 명령 실행"·"모든 파일 수정"·"권한 추가 요청"이나 글자(예: git push)를 정하면, 그런 일은 AI에게 묻지 않고 "사람이 직접 할 일" 카드로 넘겨요. 직접 했으면 **직접 처리함**.

### 9장 작업 서랍(질문 하나하나 보기)

**누구:** 모두 · **쓰는 화면:** [작업 서랍](#작업-서랍)

1. 왼쪽 아래 **작업**(승인 대기 수 배지).
2. "승인 대기·사람이 직접 할 일", "진행 중·확인 필요", "최근"이 나와요.
3. 줄의 **자세히** → 질문·상태·엔진·접수·마지막 변경·재개 확인("같은 세션")·답. **대화로**를 누르면 그 대화가 열려요.

메신저에서 받은 작업 링크(`/#task=…`)를 열면 그 작업이 바로 펼쳐져요. 내 것이 아니면 "이 작업을 볼 수 없어요".

### 10장 AI 직원과 방

**누구:** 모두 · **쓰는 화면:** [연결 설정](#연결-설정), [방 창](#방-만들기방-고치기-창), [방 화면](#방-화면), [메신저 고급 탭](#관리--메신저-고급)

1. 대화마다 이름 붙이기: **연결 설정 → AI 직원 이름·역할**에 이름(빈칸 없이 1~20자)·아이콘(이모지 하나)을 넣고 역할을 고른 뒤(역할은 2번에서 먼저 만들어 둔 것 중에서 고름 — 없으면 칸에 "만든 역할 없음"), **저장** → "AI 직원 정보를 저장했어요". 목록에 아이콘과 @이름이 보여요.
2. 역할(관리자): **설정 → 관리 → 메신저 고급 → 역할 → 역할 만들기·고치기**에서 역할 ID·이름·만들 수 있는 엔진·허용 권한·AI 역할 안내를 넣고 **역할 저장**. 가입자도 이 역할을 골라 쓸 수 있어요.
3. 방 만들기: 왼쪽 "방" 옆 **＋ 방** → 방 이름, 구성원(1~10명), 대표, 공통 안내 → **저장** → "방을 만들었어요".
4. 방에서 쓰기: @이름으로 부르면 그 직원이, 아무도 안 부르면 대표가 답해요. 답마다 **다른 AI 직원에게 넘기기**.
5. 방 지우기: 방 화면 **방 설정 → 방 지우기**(방 기록만 지우고 직원 대화는 그대로).

### 11장 작업 폴더와 예약

**누구:** 모두 · **쓰는 화면:** [작업 탭](#내-설정--작업)

- **작업 폴더:** **설정 → 작업 → 작업 폴더**(허브는 "PC·칸"을 먼저 고름)에서 폴더 이름과 경로를 **등록**하고, "AI 직원" 표의 **폴더 정하기**로 직원마다 개인 폴더와 공유 폴더(읽기만/읽기·쓰기)를 붙여요. 저장할 때 "실제로 막히는 정도"를 보여 주고 확인을 받아요.
- **예약 작업:** **설정 → 작업 → 예약 작업**에서 대화·언제(매일/간격/한 번)·하루 최대·보낼 질문을 넣고 **예약 만들기**(확인 창). 그때 그 대화에 질문이 가고 답이 대화(와 연결된 메신저 방)에 쌓여요. 처리 중이거나 PC가 꺼져 있으면 그 회차는 건너뛰어요.

### 12장 메신저로 쓰기

**누구:** PC형·허브 관리자(봇 주인), 가입자(공용 봇 연결) · **쓰는 화면:** [메신저 연결 마법사](#메신저-연결-마법사), [메신저 탭](#내-설정--메신저)

**봇 주인(PC형·허브 관리자) — 시험 확인**

1. 왼쪽 아래 **메신저** → "어느 메신저로 쓸까요?"에서 메신저를 골라요. 줄마다 "설정 전"·"연결됨"·"연결 안 됨 · 눌러서 토큰 확인"·"쓸 수 없음"이 보여요.
2. 안내대로 봇을 만들고 토큰을 붙여 넣은 뒤 **연결**(앞뒤 공백은 저절로 지워요).
   - 토큰이 틀리면 "봇이 연결되지 않았어요 — 토큰이 맞지 않아요. 뒤로 가서 토큰을 확인하세요."
   - 카카오톡·라인은 공개 주소가 필요해 **허브(또는 공개 중계)에서** 연결해요. PC형에서 누르면 그 이유가 나와요.
3. 봇이 연결되면 "봇에게 이 숫자를 보내세요"와 6자리 숫자(10분)가 나와요. 그 숫자를 봇에게 보내면 보낸 사람이 봇 주인으로 등록돼요.
4. "연결됐어요". 봇에게 `/sessions`, `/use 번호`로 대화를 고른 뒤 질문해요.

봇 여러 개·부르는 이름·허용 사용자는 **설정 → 메신저 → 봇**, 허용되지 않은 사람의 요청은 **설정 → 메신저 → 허용 요청**. 자세히는 [메신저 설정 설명서](MESSENGER_MANUAL.md).

**가입자 — 공용 봇에 내 메신저 계정 잇기**

1. 왼쪽 아래 **메신저**(또는 **설정 → 메신저**) → "메신저 연결".
2. **연결 숫자 받기** → 나온 숫자를 허브의 공용 봇에게 보내요.
3. 그 메신저 계정에서는 내 대화만 보여요. 끊기는 같은 표의 **끊기**.

### 14장 이어온 앱(휴대폰·PC)

**누구:** 모두 · **쓰는 화면:** [앱과 기기 탭](#내-설정--앱과-기기)

### 15장 여러 사람이 같이 쓰기

**누구:** 허브 관리자(15-1), 가입자(15-2) · **쓰는 화면:** [허브 보안 탭](#관리--허브-보안), [로그인](#로그인), [승인 대기](#승인-대기)

#### 15-1. 관리자

1. **설정 → 관리 → 허브 보안 → 여러 사람 → 여러 사람 쓰기(가입 신청 받기)** 켜기(확인 창). 로그인 화면에 **가입 신청**과 약관 동의 칸이 생겨요.
2. 다른 사람이 허브에 닿을 수 있게 같은 탭 위 **보안(허브 접속 제한)**을 열어요(열어도 로그인은 필요해요).
3. 신청이 오면 같은 칸 표에서 **승인** 또는 **거절**.
4. 쓰는 중인 사람: **끊기**(바로 로그아웃)·**다시 켜기**·**임시 비밀번호**(브라우저 알림 창에 한 번 보임)·**지우기**. **가입자 하루 질문 한도**와 사람별 **한도**로 하루 질문 수를 정해요.

#### 15-2. 가입자(시험 확인)

1. 허브 주소를 열고 이메일·비밀번호(10자 이상)를 넣은 뒤 **이용 약관**·**개인정보 처리방침**을 읽고 동의 칸을 눌러 **가입 신청** → 확인 창 → "승인을 기다려요".
2. 관리자가 승인하면 같은 이메일·비밀번호로 **로그인**. 왼쪽 위에 "허브 · 주소 · 내 이메일".
3. 내 PC 연결: **설정 → 앱과 기기 → 기기 → PC 연결 링크 → 링크 만들기** → 그 링크를 내 PC에서 열고 **연결**(4장과 같아요).
4. 대화 연결(5장)·새 세션(6장, 내 PC에만)·질문(7장)을 해요. 메신저는 12장 "가입자".
5. 비밀번호 바꾸기: **설정 → 계정 → 내 비밀번호**.

가입자 설정에 보이는 탭: **PC 설정·작업·계정(내 비밀번호)·메신저(메신저 연결)·앱과 기기**. 허브 설정·보안·봇·계정 로그인은 관리자만 해요. 다른 사람의 대화·PC는 보이지 않아요.

## 2부 화면별 설명

화면마다 **여는 법 · 기능·목적 · 사용 순서 · 주요 항목**을 적었어요.

### 대화 화면(`/`)

#### 로그인

- **여는 법:** 허브 주소로 접속(로그인 전). PC 화면은 자동 로그인이라 안 보여요.
- **기능·목적:** 허브에 들어가기, 가입 신청, 화면 언어 고르기.
- **사용 순서:** 관리자는 이메일 비우고 비밀번호 → **로그인**. 가입자는 이메일·비밀번호 → **로그인**. 처음이면 동의 칸 → **가입 신청**.

| 항목 | 설명 |
| --- | --- |
| "이메일(관리자는 비워 두세요)" | 가입자 이메일. 관리자는 비워요 |
| "비밀번호" | 10자 이상 |
| **로그인** | 들어가기. 틀리면 "비밀번호가 맞지 않아요", 5번 틀리면 15분 잠김 |
| 동의 칸 "이용 약관과 개인정보 처리방침에 동의해요(가입 신청할 때)" | 여러 사람 쓰기가 켜진 허브에만 보여요. 두 글은 새 탭으로 열려요 |
| **가입 신청** | 신청 확인 창 → 승인 대기. 이미 신청한 이메일이면 "이미 신청한 이메일이에요 — 로그인해 보세요", 이메일 모양이 틀리면 "이메일 모양이 맞지 않아요" |
| 언어 선택(한국어/English) | 화면 언어 |

#### 관리자 만들기

- **여는 법:** 관리자가 없는 허브를 처음 열 때.
- **기능·목적:** 허브 관리자 비밀번호 정하기.
- **사용 순서:** 비밀번호 두 번 → **만들기** → 바로 대화 화면.

| 항목 | 설명 |
| --- | --- |
| "비밀번호"·"비밀번호 다시" | 10자 이상, 같아야 해요 |
| **만들기** | 다른 탭에서 먼저 만들었으면 "관리자가 이미 있어요. 로그인하세요" |

#### 승인 대기

### 알려진 제한

- 메신저 실제 계정(텔레그램·디스코드·슬랙·카카오·라인)으로 봇 주인 등록까지는 이번 시험에서 하지 못했어요(시험용 실제 봇 계정이 없음). 가짜 토큰 거절·안내 문구까지 확인했어요.
- 허브는 PC의 Codex 공유 서버 여부를 몰라서, 공유 서버가 없는 PC 대화도 "동시 사용"으로 바뀌어요. 보낼 때 PC가 거절해요(보통은 빠른 응답을 쓰세요).
- 가입자 새 세션 한도 줄의 개수는 허브 기준으로 세요(가입자 PC의 개수와 다를 수 있어요).
- 같은 컴퓨터에서 `localhost`로 두 이어온 화면(다른 포트)을 열면 로그인이 서로 덮여요(브라우저 쿠키는 포트를 가리지 않음). 각각 다른 주소(127.0.0.1과 localhost)로 열어요.

## 시험 근거와 아직 확인하지 못한 것

2026-11-23 AI 작업자가 시험 환경을 직접 만들어 확인했어요.
