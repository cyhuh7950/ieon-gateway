# 이어온 가입자 따라 하기 — 다른 사람의 허브를 같이 쓰기

이 문서는 **다른 사람(허브 주인)이 운영하는 이어온 허브에 가입해서 쓰는 사람**을 위한 설명서입니다. 허브 주인(관리자)이 해야 할 일은 [사용 설명서](MANUAL.md)의 "여러 사람이 같이 쓰기"에 있습니다.

- 작성 2026-11-19. 기준 허브: `ieun-gateway.sinsan.kr`(주소는 허브마다 다릅니다 — 허브 주인에게 받으세요).
- 가입하면 **내 PC의 내 Codex·Claude 세션만** 씁니다. 사용량도 내 계정으로 나갑니다. 내 대화는 다른 가입자에게도, 허브 주인에게도 화면으로는 보이지 않습니다.

---

## 0. 준비물 (시작 전에)

| 준비물 | 왜 필요한가 |
| --- | --- |
| 허브 주소 | 허브 주인에게 받습니다. 허브 주인이 **여러 사람 쓰기**를 켜고, 허브 접속 제한도 열어 두어야 들어갈 수 있습니다 |
| 이메일 주소 하나 | 가입 아이디로 씁니다(메일은 보내지 않습니다) |
| 비밀번호(10자 이상) | 직접 정합니다 |
| 내 PC(Windows) | AI가 실제로 일하는 곳입니다. 이 PC에 **Codex 앱(또는 Claude Code)이 깔려 있고 내 계정으로 로그인**돼 있어야 합니다 |
| 내 PC에 이어온 설치 | 허브와 내 PC를 잇는 프로그램입니다. 설치 순서는 [처음 쓰는 사람용 따라 하기](BEGINNER_GUIDE.md) 2~3장 |
| (선택) 텔레그램·디스코드·슬랙·라인·카카오톡 계정 | 메신저로도 쓰고 싶을 때만(허브 주인이 그 메신저 봇을 켜 둔 것만) |
| (선택) 안드로이드 휴대폰 | 이어온 앱으로 쓰고 싶을 때만 |

---

## 1. 가입 신청

1. 브라우저(크롬·엣지)에서 허브 주소를 엽니다.
2. 로그인 화면에서 **이메일**과 **비밀번호**를 넣고, **이용 약관·개인정보 처리방침**을 읽은 뒤 동의 칸을 누르고 **가입 신청**을 누릅니다.
   - "가입 신청" 단추가 없으면 허브 주인이 아직 여러 사람 쓰기를 켜지 않은 것입니다.
3. 확인 창에서 **확인** → **"승인을 기다려요"** 화면이 나오면 신청 끝입니다.
4. 허브 주인에게 "가입 신청했어요"라고 알려 주세요. 승인되기 전에는 아무 기능도 쓸 수 없습니다.

☐ 확인 1: "승인을 기다려요" 화면이 나왔다.

## 2. 로그인

1. 승인되면 허브 주소를 다시 열고, **이메일·비밀번호**를 넣어 **로그인**합니다.
2. 처음에는 대화가 하나도 없습니다(정상 — 아직 내 PC를 연결하지 않았습니다).

| 이런 말이 나오면 | 뜻 |
| --- | --- |
| 승인을 기다려요 | 아직 승인 전입니다 |
| 쓸 수 없는 계정이에요 | 허브 주인이 거절했거나 끊었습니다 |
| 비밀번호가 맞지 않아요 | 다시 넣거나, 허브 주인에게 **임시 비밀번호**를 부탁하세요 |

## 3. 내 PC를 허브에 연결

1. 허브 화면 왼쪽 아래 **⚙ 설정** → 위쪽 **밖에서도 쓰기** → **PC 연결 링크**의 **링크 만들기** → **복사**.
2. 나온 링크를 **내 PC**에서 엽니다(내 PC의 이어온 설정 화면이 열림) → 이 PC 이름을 넣고 **연결**.
3. 허브 화면 **설정 → 밖에서도 쓰기**의 기기 목록에 내 PC가 "연결됨"으로 보이면 끝입니다. 다른 가입자의 PC는 보이지 않습니다.

☐ 확인 3: 기기 목록에 내 PC가 보인다.

## 4. 대화 쓰기 — 쓰던 대화 연결 또는 새 세션

**쓰던 Codex 대화 이어 쓰기**

1. 허브 첫 화면 왼쪽 **＋ 대화 연결** → 내 PC에서 최근에 쓴 Codex 대화 목록이 나옵니다(10초쯤 걸림). PC가 둘 이상이면 위쪽 **PC** 칸에서 고릅니다.
2. 이어 쓸 대화를 누르면 바로 연결되고 그 대화가 열립니다. 질문은 내 PC의 같은 Codex 대화로 이어집니다.
   - 내 PC가 꺼져 있으면 "그 PC가 꺼져 있어요"가 나옵니다 — PC에서 이어온을 켜고 다시 누르세요.
   - 목록에 없으면 **고급: 대화 ID 직접 넣기**.
   - 같은 대화를 PC의 Codex 앱에서 열어 둔 채 질문하면 "사용 중"으로 거절됩니다(앱에서 그 대화를 닫으면 됨).

**새 세션 만들기**

1. 허브 첫 화면 왼쪽 위 **＋ 새 세션** → 엔진(Codex·Claude)·이름을 넣고 **만들기**. 만들 곳은 내 PC로 정해집니다(켜진 내 PC가 없으면 "기기 없음").
2. 만든 대화에 질문을 보내면 내 PC의 엔진이 답합니다.

☐ 확인 4: ＋ 대화 연결에 내 PC의 Codex 대화가 나오고, 고르면 대화 목록에 생긴다.

## 5. 메신저로도 쓰기 (선택)

1. 허브 화면 **설정 → 밖에서도 쓰기 → 메신저 연결**에 "같이 쓰는 봇"(예: 텔레그램 @…bot)이 보입니다.
2. **연결 숫자 받기** → 나온 6자리 숫자를 그 봇에게 **1:1 대화로** 그대로 보냅니다(10분 안에 한 번만).
3. 봇이 **"이어온 계정과 연결됐어요"**라고 답하고, 같은 화면 목록에 내 메신저 계정이 생기면 연결 끝입니다. 이제 그 봇에서 `/sessions`를 치면 **내 대화만** 보입니다. `/use 번호`로 대화를 고르고 질문하면 됩니다.
4. 그만 쓰려면 같은 목록에서 **끊기**.

- 단체방보다 **봇과 1:1 대화**를 권합니다(단체방은 방 하나가 대화 하나에 묶입니다).
- 숫자를 5번 틀리면 15분 동안 막힙니다. 숫자를 새로 받으세요.

☐ 확인 5: 봇에서 `/sessions`를 치면 내 대화만 나온다.

## 6. 휴대폰 앱으로 쓰기 (선택, 안드로이드)

1. 휴대폰 브라우저 주소창에 **`<허브 주소>/app`** → 앱 파일이 받아집니다 → 눌러서 설치(처음 한 번 "출처를 알 수 없는 앱" 허용).
2. 허브 화면 **설정 → 내 프로그램 연결 → 연결 코드 만들기** → 앱에 허브 주소와 8자리 코드를 넣고 **연결**.
3. 알림 허용 창이 뜨면 **허용** — 앱을 닫아도 "○○가 답했어요"가 옵니다.

자세한 순서는 [이어온 앱 따라 하기](APP_GUIDE.md).

## 7. 그 밖에

- **비밀번호 바꾸기:** 설정 → 밖에서도 쓰기 → **내 비밀번호**. 바꾸면 다른 곳의 로그인은 끊깁니다.
- **비밀번호를 잊었을 때:** 허브 주인에게 임시 비밀번호를 부탁하고, 로그인한 뒤 위에서 바꾸세요.
- **브라우저 알림:** 허브 화면 왼쪽 아래 🔕 알림 → 허용하면 탭을 닫아도 알림이 옵니다.
- **예약 질문:** 설정 → 대화 → 예약 작업. 답은 대화와 연결한 메신저 방·앱 알림으로 옵니다.
- **하루 질문 한도:** 허브 주인이 정했으면 "오늘 보낼 수 있는 질문 수를 다 썼어요"가 뜨고 보내지 않습니다. 한국 시간 0시에 다시 쓸 수 있어요.
- **가입자가 할 수 없는 것:** 허브 설정·보안, 메신저 봇 설정, 다른 사람의 PC·대화, 허브 서버의 엔진 칸. 필요하면 허브 주인에게 말하세요.
- **그만 쓰기:** 허브 주인에게 계정 삭제를 부탁하면 내 이어온 기록(대화 기록·방·예약·연결한 PC·앱 연결)이 모두 지워집니다. 내 PC의 원래 Codex·Claude 기록은 남습니다.
