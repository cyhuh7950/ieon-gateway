## B. 허브형 (`https://ieun-gateway.sinsan.kr`)

| # | 하는 일 | 기대 결과 | 결과 |
| --- | --- | --- | --- |
| B1 | 허브 열기 → **관리자 만들기**(비밀번호 10자 이상, 두 번) → 위쪽 **로그아웃** → 비밀번호로 **로그인** | 토큰 칸 없음, 로그인됨 | |
| B2 | 허브 봇 관리 → 설정 → **보안** 확인(바꾸지 않음) | "지금 내 주소", IP 허용 목록 표시 | |
| B3 | 이 PC 화면 → 봇 관리 → **허브에 연결**: 주소 `https://ieun-gateway.sinsan.kr`, 이름(예: 집 PC) → **연결** | 6자리 코드 표시 | |
| B4 | 허브 화면 → 봇 관리 → 기기 → **연결 요청**: 같은 코드 확인, 등록 방식 **기존 기기 대체: 신산 PC (h_pc)** → **승인** | PC 화면 "연결됨", 허브 세션 탭 "시험 표식 확인" = 보낼 수 있음 | |
| B5 | (선택) 허브 설정 → **Codex 로그인(이 허브)** → 로그인 → 나온 주소에서 코드 승인 | "로그인됨" | |
| B6 | (선택) 허브 봇 관리 → **외부 프로그램(API 키)** → 이름 넣고 발급 → 닫기 → 폐기 | 키 한 번 표시, 폐기됨 | |

> 텔레그램·디스코드·슬랙 봇 토큰은 지금 **이 PC 메신저가 쓰고 있다**. 같은 토큰을 허브에도 넣으면 두 곳이 같은 봇을 받아 메시지가 나뉘므로, 허브에서 메신저를 시험하려면 허브용 봇을 따로 만들어 그 토큰만 넣는다.
