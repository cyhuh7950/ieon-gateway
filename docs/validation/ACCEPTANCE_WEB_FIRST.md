### 인수 지적 수정 (2026-11-08, 한 번에)

1. **아이콘:** 이어온 아이콘(`src/pilot/web/ieon.ico`, `scripts/make-icon.mjs`로 생성, 청록 바탕 흰 "이")을 바로 가기(`IconFile`)와 브라우저 탭(`/favicon.ico`)에 붙임.
2·3. **관리 화면을 탭으로:** 봇 관리 화면을 탭 9개(이 PC·봇·메신저·카카오·세션 등록·새 세션·역할·기기·허브 보안·Codex·외부 프로그램)로 나눔. "이 PC" 탭은 PC에서만(첫 탭), "허브 보안·Codex"는 허브에서만. 마지막에 본 탭 기억. 시험 화면에서 모든 탭이 한 화면 높이(768) 안.
4. **결과 알림:** 화면 위쪽에 떠 있는 알림으로(아래에서 눌러도 보임), 성공·안내는 6초 뒤 사라지고 오류는 남음.
5. **제목:** 제목 옆에 "이 PC" 또는 "허브 · 주소", 브라우저 탭 제목 "이어온 — 이 PC/허브".

**발견·수정(같은 날):**
1. **연결부 중복(버그):** 설정을 바꿀 때 허브 연결부를 끊고 바로 다시 띄우면, 늦게 도착한 이전 연결부의 종료 알림이 새 연결부 참조를 지우고 또 띄워서 추적 안 되는 연결부가 쌓였다(시험 PC에서 허브용 3개). → 종료 알림은 지금 연결부일 때만 처리(`hub-link.mjs`·`device-settings.mjs`), 회귀 테스트 추가. 고친 뒤 설정 4번 변경해도 로컬 1·허브용 1개.
2. **틀린 키 + 쿠키:** Authorization 키가 틀려도 브라우저 쿠키로 통과하던 것 → 키를 보냈으면 그 키로만 판단(401), 테스트 추가.
3. **화면:** 허브 Codex 로그인 칸이 첫 상태 확인(몇 초) 동안 숨겨짐 → "확인 중…" 먼저 표시. PC 화면에 허브 전용 "연결 요청" 칸이 보임 → 허브에서만. "기존 세션 등록" 안내의 `server.json`·`connector.json` 문구 → 화면 안내로.

**기본 시험에서 하지 않은 것(이유):** 진짜 허브 관리자 만들기(신산님 비밀번호), 실제 Codex 로그인(신산님 계정), 카카오톡·메신저 실제 대화(신산님 계정·인수 때), 이 PC 실제 실행 스위치(켜는 동안 실제 메신저 질문이 실행될 수 있어 시험 PC로 대신), 모델 호출.
