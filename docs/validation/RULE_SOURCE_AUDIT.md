# 규칙 출처 점검 — AGENTS.md 안전 규칙과 코드의 막는 장치(2026-11-18)

신산님 "규칙 점검 진행"(2026-11-18). 기준: 제1원칙(2026-11-17 신산님) — **사용자의 편의가 안전·보안보다 우선**, AI가 임의로 만든 규칙으로 기능을 막거나 불편하게 하지 않음, 규칙을 인용할 때 누가 정했는지(신산님·PMO·AI) 구분. 이 문서는 **조사와 고를 목록**이다. 바꾼 것은 없다 — 바꾸는 것은 신산님이 정한 것만.

## 0. 조사 방법과 한계

- **AGENTS.md:** 저장소 이력은 2026-11-05 이전(옛 저장소 `sinsan-develop/ieon-gateway`)이 한 커밋으로 합쳐져 있어 줄마다 누가 넣었는지 Git으로는 알 수 없다. 대신 `docs/WORK_STATUS.md`의 2026-10-29 요구·인터뷰 기록(신산님이 준 요구 문서, "인터뷰 확정 사항"), `docs/design/DESIGN.md`, 지침 안의 날짜·이름 표시로 출처를 찾았다.
- **코드:** 도우미(읽기 전용)가 `src/pilot/**`·`src/relay`·`src/hub`·설치 스크립트·compose에서 막는 장치·기본값·한도·확인 단계를 약 100개 모았고(파일:줄 포함), 그중 신산님께 불편이 큰 것은 직접 코드를 열어 다시 확인했다(아래 "확인함").
- **출처 표시:** **신산님**(기록에 신산님 결정·지시로 남음) · **PMO**(공통 규칙) · **AI**(AI 작업자가 설계·구현 중 넣었고 신산님 결정 기록이 없음) · **불명**(옛 저장소 이력이 없어 확인 못 함).

### 2-3. 그대로 두는 것이 맞아 보이는 것(신산님 결정 또는 효과 큼)

업무 대화 제외(신산님), 자동 재전송·유료 전환·새 대화 대체 금지(신산님 인터뷰), 로그 원문 금지(신산님), 서비스용 봇은 API 계정만(신산님 SV3), 작업 모드는 사람이 허용(신산님 요구 문서), 허브 접속 제한(신산님 W7), 동시 질문 수(신산님 진행 지시, 웹에서 바꿈), Desktop이 잡고 있을 때·사람이 쓰는 중일 때 보내지 않기(같은 세션 재사용 목표에서 나옴 — 겹치면 대화가 갈라짐), 임시 폴더 거절(실측으로 막히지 않음이 확인된 곳).
