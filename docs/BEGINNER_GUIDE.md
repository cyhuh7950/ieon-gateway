# 이어온 처음 쓰는 사람을 위한 따라 하기

기준: 2026-11-08(웹 중심 재설계 W0~W8). **설치는 한 번만 하고, 나머지 설정은 모두 웹 화면에서 합니다.** 토큰을 만들거나 파일에 옮겨 적을 일은 없습니다.

## 0. 먼저 알아 둘 것

### 이어온이란

이미 쓰고 있는 **Codex 대화**와 **Claude Code 세션**에 웹 화면·메신저(텔레그램·디스코드·슬랙·카카오톡)·내 프로그램에서 질문을 보내고 답을 받게 해 주는 도구입니다. 새 대화로 바꾸지 않고 **같은 대화를 이어서** 씁니다.

### 두 가지 쓰는 방법

| | **PC 완결형(ieon)** | **허브형(ieun)** |
| --- | --- | --- |
| 무엇을 켜 두나 | 내 PC 하나 | 공개 서버(허브) + 내 PC |
| 웹 화면 | 내 PC의 `http://127.0.0.1:28760` | 허브 주소(예: `https://ieun-gateway.sinsan.kr`) |
| PC가 꺼지면 | 봇이 답하지 않음 | 허브의 새 세션은 답하고, PC 세션만 "PC 연결 끊김" |

처음에는 PC 완결형으로 시작하고, 필요할 때 7절의 "허브에 연결"을 하면 됩니다.

### 꼭 지킬 약속

- **실제 실행**(AI 호출)은 필요할 때만 켜고, 다 쓰면 끕니다(4절).
- 업무용 중요한 대화는 허용 목록에 넣지 않습니다. 시험용 대화로 먼저 해 보세요.
- 비밀번호·봇 토큰·API 키는 채팅이나 문서에 붙이지 않습니다.

## 1. 설치 (한 번만)

준비물: Windows 11, [Node.js 24](https://nodejs.org), 그리고 쓰려는 AI 앱(Codex 앱 또는 Claude Code). AI 앱의 로그인은 그 앱에서 평소처럼 해 둡니다.

1. 이어온 폴더를 받습니다(관리자가 준 압축 파일을 풀거나 저장소를 내려받기).
2. 그 폴더에서 PowerShell을 열고 **아래 한 줄**을 실행합니다.

```powershell
pwsh scripts/install.ps1
```

설치가 하는 일: 부품 설치 → 설정과 내부 토큰 만들기(값은 보이지 않음) → 로그온할 때 창 없이 자동 시작 → 지금 시작 → 브라우저로 웹 화면 열기 → 바탕화면에 **이어온** 바로 가기.

> 설치는 **실제 실행을 끈 채로** 시작합니다. 이 상태에서는 AI가 호출되지 않습니다.

## 2. 웹 화면 열기

바탕화면의 **이어온**을 엽니다. 이 PC에서 연 화면은 **자동으로 로그인**됩니다.

- 위쪽 **세션**: 질문하는 곳
- 위쪽 **봇 관리**: 모든 설정(이 PC 설정·메신저 봇·카카오·허브 연결·외부 프로그램)

## 3. 이어 쓸 Codex 대화 허용하기

**봇 관리 → 이 PC 설정**의 "허용 목록에 추가"에 다음을 넣습니다.

- **Codex 대화 ID**: Codex 앱에서 이어 쓸 대화를 연 상태로 주소·대화 정보에서 보이는 `01a1…` 형식의 ID
- **연결 방식**: 보통 "번갈아 쓰기"(이어온으로 보낼 때 Codex 앱에서 그 대화를 열어 두지 않기)
- **작업 폴더**(선택): 그 대화가 작업하는 폴더의 전체 경로

추가하면 연결부가 새 설정으로 바로 다시 시작합니다. 세션 목록에 나오게 하려면 **기존 세션 등록**에서 같은 대화를 이름과 함께 등록합니다.

## 4. 실제 실행 켜기·끄기

**봇 관리 → 이 PC 설정 → "실제 실행 켜기"**를 체크하면 확인 창이 뜨고, 확인하면 그때부터 질문마다 AI가 호출됩니다. 다 쓰면 체크를 끕니다. 이 스위치는 **이 PC에서 연 화면에서만** 바꿀 수 있습니다(휴대폰·허브 화면에서는 보기만).

## 5. 질문하기

**세션** 탭에서 세션을 고르고 질문을 보내면 답이 아래에 나옵니다. 상태 문구가 "확인 필요"면 원래 앱(Codex·Claude Code)에서 실행됐는지 보고 화면의 버튼으로 정리합니다(자동으로 다시 보내지 않습니다).

**Claude Code 세션**은 Claude Code를 이어온 채널과 함께 켜 둔 동안만 받습니다. Claude Code 사용 설명은 [MANUAL](MANUAL.md)의 "Claude 채널 세션"을 보세요.

## 6. 메신저 봇 연결

1. 메신저에서 봇을 만들고 **봇 토큰**을 받습니다(텔레그램은 BotFather, 디스코드·슬랙은 개발자 화면 — [MESSENGER_MANUAL](MESSENGER_MANUAL.md) 4절).
2. **봇 관리 → 봇 목록**에서 그 메신저의 봇(처음엔 `default`)을 고르고, 편집 칸의 **토큰**에 붙여 넣고 저장합니다. 1분 안에 "연결됨"이 됩니다. 저장한 토큰은 다시 보이지 않습니다.
3. 메신저에서 봇에게 아무 말이나 보낸 뒤, **봇 관리 → 설정 → 허용 요청**에 내 이름이 뜨면 **허용**을 누릅니다.
4. 메신저에서 `/sessions`로 세션 목록을 보고 `/use 1`처럼 골라 질문합니다.

### 카카오톡

**봇 관리 → 설정 → 카카오 스킬 URL**에서 **복사**를 누르고, 카카오 오픈빌더의 스킬 URL 칸에 붙여 넣어 저장합니다. 위쪽에 "이 PC 연결됨"(PC 완결형) 또는 허브 화면이면 허브 주소로 나옵니다.

## 7. 허브형으로 쓰기

1. **허브 처음 열기**: 허브 주소를 열면 **관리자 만들기**가 나옵니다. 비밀번호(10자 이상)를 두 번 넣습니다. 다음부터는 이 비밀번호로 로그인합니다.
2. **PC를 허브에 연결**: 내 PC 화면의 **봇 관리 → 허브에 연결**에 허브 주소와 이 PC 이름을 넣고 "연결" → 6자리 코드가 나옵니다.
3. **허브에서 승인**: 허브 화면의 **봇 관리 → 기기 → 연결 요청**에 같은 코드가 뜨면 **승인**. 같은 PC를 다시 연결할 때는 "기존 기기 대체"를 고르면 세션 등록을 그대로 씁니다.
4. **허브에서 새 세션 쓰기**(선택): 허브 화면 **설정 → Codex 로그인(이 허브)**에서 "로그인" → 나온 주소를 열어 코드를 넣고 승인 → 같은 칸의 "허브 새 세션 실제 실행 켜기"와 **새 세션** 설정의 "켜기".
5. **허브 접속 제한**: 허브 화면 **설정 → 보안**에서 허브를 열 수 있는 곳(내 IP·Cloudflare Access·Tailscale)을 정합니다. 지금 접속한 곳이 막히는 변경은 저장되지 않습니다.

## 8. 내 프로그램에서 쓰기

**봇 관리 → 외부 프로그램(API 키)**에서 프로그램 이름을 넣고 **키 발급** → 한 번만 보이는 키를 그 프로그램 설정에 넣고, 볼 수 있는 세션을 체크해 저장합니다. 필요 없어지면 **폐기**. API 사용법은 [API_GUIDE](API_GUIDE.md).

## 9. 끄기·지우기

- 잠깐 멈추기: 실제 실행만 끄면 됩니다(4절). 이어온 자체는 켜 둬도 AI를 부르지 않습니다.
- 자동 시작까지 없애기: 이어온 폴더에서 `pwsh scripts/install.ps1 -Uninstall`(설정·대화 기록은 남음). 다시 쓰려면 1절의 설치를 다시 실행합니다.

## 10. 문제가 있을 때

| 보이는 것 | 할 일 |
| --- | --- |
| 바로 가기를 열어도 화면이 안 나옴 | `pwsh scripts/install.ps1`을 다시 실행(이미 설치돼 있으면 다시 시작만 함) |
| 봇이 "토큰 없음" | 봇 관리에서 그 봇의 토큰 칸에 다시 넣기 |
| 메신저에서 답이 없음 | 설정 → 허용 요청에 내가 있으면 "허용" |
| "PC 연결 끊김" | 그 PC가 켜져 있는지, PC 화면의 "허브에 연결"이 "연결됨"인지 |
| Codex 질문이 "사용 중"으로 거절 | Codex 앱에서 그 대화를 닫고 다시 보내기 |

개발·문제 해결용 명령(`scripts/ieon.ps1`)은 [MANUAL](MANUAL.md) 부록에 있습니다. 보통은 쓸 일이 없습니다.
