기준: 2026-11-12(새 화면 U1~U7 반영). **설치는 한 번만 하고, 처음 한 번 대화 하나만 고르면 바로 쓸 수 있습니다. 나머지 설정은 화면의 설정(톱니)에서 합니다.** 내부 토큰을 만들거나 파일에 옮겨 적을 일은 없습니다.

## 0. 먼저 알아 둘 것

### 이어온이란

이미 쓰고 있는 **Codex 대화**와 **Claude Code 세션**에 웹 화면·메신저(텔레그램·디스코드·슬랙·카카오톡)·내 프로그램에서 질문을 보내고 답을 받게 해 주는 도구입니다. 새 대화로 바꾸지 않고 **같은 대화를 이어서** 씁니다.

### 두 가지 쓰는 방법

| | **PC 완결형(ieon)** | **허브형(ieun)** |
| --- | --- | --- |
| 무엇을 켜 두나 | 내 PC 하나 | 공개 서버(허브) + 내 PC |
| 웹 화면 | 내 PC의 `http://127.0.0.1:28760` | 허브 주소(예: `https://ieun-gateway.sinsan.kr`) |
| PC가 꺼지면 | 봇이 답하지 않음 | 허브의 새 세션은 답하고, PC 세션만 "PC 연결 끊김" |

처음에는 PC 완결형으로 시작하고, 필요할 때 8절의 "허브에 연결"을 하면 됩니다.

### 꼭 지킬 약속

- **AI 응답**(AI 호출)은 필요할 때만 켜고, 다 쓰면 끕니다(4절).
- 업무용 중요한 대화는 연결하지 않습니다. 시험용 대화로 먼저 해 보세요.
- 비밀번호·봇 토큰·API 키는 채팅이나 문서에 붙이지 않습니다.

## 1. 설치 (한 번만)

**준비물**

- Windows 11
- [Node.js 24](https://nodejs.org)
- 쓰려는 AI 앱(Codex 앱 또는 Claude Code). 로그인은 그 앱에서 평소처럼 해 둡니다.

**설치**

1. 이어온 폴더를 받습니다(관리자가 준 압축 파일을 풀거나 저장소를 내려받기).
2. 그 폴더에서 PowerShell을 열고 **아래 한 줄**을 실행합니다.

```powershell
pwsh scripts/install.ps1
```

설치가 하는 일은 다음과 같습니다.

1. 부품 설치
2. 설정과 내부 토큰 만들기(값은 보이지 않음)
3. 로그온할 때 창 없이 자동으로 시작하도록 등록
4. 지금 시작
5. 웹 화면 열기
6. 바탕화면에 **이어온** 바로 가기 만들기(Edge가 있으면 Edge 앱 창으로, 없으면 브라우저 탭으로 열림)

설치가 끝나면 "처음 한 번 대화 하나만 고르면 바로 쓸 수 있고, 나머지는 화면의 '설정'(톱니)에서 합니다"라는 안내가 나옵니다.

> 설치는 **AI 응답을 끈 채로** 시작합니다. 이 상태에서는 AI가 호출되지 않습니다.

## 2. 시작하고 화면 열기

**시작:** 따로 할 일이 없습니다. Windows에 로그온하면 이어온이 창 없이 자동으로 켜지고, 메신저 봇도 함께 켜집니다.

**화면 열기:** 바탕화면의 **이어온**을 엽니다. 이 PC에서 연 화면은 **자동으로 로그인**됩니다. 허브 화면은 관리자 비밀번호로 로그인합니다(8절).

화면 구성은 이렇습니다.

- **왼쪽:** 연결한 대화 목록(엔진, 상태 한 줄, 처리할 일 개수). 맨 위에 **＋ 대화 연결**, 왼쪽 아래에 **메신저**와 **설정**(⚙).
- **가운데:** 고른 대화. 위쪽에 대화 이름·상태, **AI 응답** 스위치(이 PC 화면만), **연결 설정**. 문제가 있으면 대화 안에 이유와 버튼이 있는 카드가 뜹니다.
- **설정**(⚙)은 아래 탭으로 나뉩니다. 위쪽 **← 대화로**를 누르면 돌아옵니다.

| 설정 탭 | 하는 일 | 보이는 곳 |
| --- | --- | --- |
| 이 PC | 실제 실행(AI 응답) 켜기·끄기, Codex 허용 목록 추가·빼기 | PC 화면 |
| 밖에서도 쓰기 | PC: 허브에 연결·다시 연결·연결 끊기·허브 잊기 / 허브: PC 연결 링크 만들기, 연결 요청 승인, 기기 목록 | 둘 다 |
| 메신저 | 봇 목록·추가·편집(이름·역할·부르는 이름·허용 사용자·볼 세션·켜기·토큰·삭제), 허용 요청, 공통 허용 사용자, 카카오 스킬 URL·중계, 역할 | 둘 다 |
| 대화 | 세션 직접 등록, 새 세션 설정(켜기·한도·잠들기·보관·기본 권한) | 둘 다 |
| 내 프로그램 연결 | API 키 발급·볼 세션·폐기 | 둘 다 |
| 허브 보안·Codex | 허브 접속 제한, 허브 Codex 로그인, 허브 새 세션 실제 실행 | 허브 화면 |

저장 결과는 화면 위쪽에 잠깐 떠서 알려 줍니다.

## 3. 이어 쓸 Codex 대화 연결하기

**처음 열면** 연결한 대화가 없으니 **처음 설정 3단계**가 자동으로 뜹니다.

1. **준비 확인:** 이 PC의 Codex 로그인 여부를 보여 줍니다. 로그인이 안 돼 있어도 계속할 수 있습니다(Codex 앱에서 로그인한 뒤 계속하면 됩니다).
2. **대화 고르기:** 이 PC에서 최근에 쓴 Codex 대화 목록에서 하나를 누릅니다(10초쯤 걸립니다). 이것만 하면 됩니다.
3. **준비됐어요:** 메신저로도 쓰기·밖에서도 쓰기(허브)는 나중에 해도 됩니다. **대화 열기**를 누릅니다.

닫았다가 다시 보려면 주소 끝에 `/#setup`을 붙여 엽니다.

**대화를 더 연결할 때:** 왼쪽 위 **＋ 대화 연결**을 누르고 목록에서 고릅니다. 누르면 허용 목록 추가와 세션 등록이 한 번에 되고(연결 방식 "번갈아 쓰기", 작업 폴더 자동), 그 대화가 바로 열립니다. 업무 대화는 목록에 나오지 않습니다.

**목록에 없으면:** **＋ 대화 연결 → 고급: 대화 ID 직접 넣기**에 대화 ID를 넣습니다. 대화 ID는 파일 탐색기 주소창에 `%USERPROFILE%\.codex\sessions`를 넣어 열고, 날짜 폴더 안의 `rollout-….jsonl` 파일 이름 끝부분에서 찾습니다.

예: `rollout-2026-10-29T21-09-09-01a18790-63c7-73e3-a60b-6ddb60fd5be8.jsonl` → `01a18790-63c7-73e3-a60b-6ddb60fd5be8`

연결 방식을 "동시 사용"으로 바꾸려면 그 대화의 **연결 설정 → 고급**에서 바꿉니다. 허용 목록을 직접 손보려면 **설정 → 이 PC**에서 합니다.

## 4. AI 응답 켜기·끄기

처음 질문을 보내면 "AI가 이 질문에 답해요" 확인 창이 뜹니다. **켜고 보내기**를 누르면 AI 응답이 켜지고 질문이 갑니다(취소하면 보내지 않습니다). 한 번 켜면 그대로 켜져 있습니다. 다 쓰면 대화 위쪽 **AI 응답** 스위치로 끕니다.

이 스위치는 **이 PC에서 연 화면에서만** 바꿀 수 있습니다. 휴대폰이나 허브 화면에서는 바꿀 수 없습니다. 메신저나 내 프로그램에서 온 질문은 웹에서 한 번 켠 뒤에만 답합니다.

## 5. 질문하기

왼쪽 목록에서 대화를 고르고 아래 입력창에 질문을 써서 **보내기**(Enter)를 누르면 답이 나옵니다. 줄을 바꾸려면 Shift+Enter.

"확인이 필요한 질문" 카드가 뜨면 원래 앱(Codex·Claude Code)에서 실행됐는지 보고 **실행됐어요** 또는 **실행되지 않았어요**를 누릅니다. 자동으로 다시 보내지 않습니다. "보내지 못한 질문" 카드의 **다시 보내기**는 보내지 않은 것이 확실할 때만 나오고, 누를 때만 보냅니다.

**Claude Code 세션**은 Claude Code를 이어온 채널과 함께 켜 둔 동안만 받습니다. 사용법은 [MANUAL](MANUAL.md)의 "Claude 채널 세션"을 보세요.

## 6. 메신저 봇 연결

1. 메신저에서 봇을 만들고 **봇 토큰**을 받습니다(텔레그램은 BotFather, 디스코드·슬랙은 개발자 화면 — [MESSENGER_MANUAL](MESSENGER_MANUAL.md) 4절).
2. 화면 왼쪽 아래 **메신저**를 누르고 메신저(텔레그램·디스코드·슬랙)를 고릅니다.
3. 짧은 안내를 보고 토큰을 칸에 붙여 넣습니다(텔레그램·디스코드 1칸, 슬랙 2칸). 이미 저장돼 있으면 바꿀 때만 넣습니다. 저장한 토큰은 다시 보이지 않습니다.
4. 봇이 연결되면 **6자리 숫자**가 크게 나옵니다. 메신저에서 그 봇에게 이 숫자만 보냅니다. "○○님이 주인으로 등록됐어요"가 나오면 끝입니다.
   - 숫자는 10분 동안 한 번만 쓸 수 있고, 5번 틀리면 잠깁니다(**숫자 새로 받기**).
   - 이미 허용된 분이 보내면 봇이 "이미 허용된 분이라 따로 등록하지 않았어요"라고 답하고 화면은 완료로 바뀝니다.
   - 숫자 대신, 봇에게 아무 말이나 보낸 뒤 대화 화면의 "허용 대기" 띠나 **설정 → 메신저 → 허용 요청**에서 **허용**을 눌러도 됩니다.
5. 메신저에서 `/sessions`로 세션 목록을 보고 `/use 1`처럼 골라 질문합니다.

봇 이름·여러 봇·허용 사용자 같은 고급 설정은 메신저 창의 **고급** 링크나 **설정 → 메신저**에서 합니다.

> **같은 봇을 PC와 허브에서 동시에 켜지 않습니다.** 텔레그램·슬랙은 메시지가 나뉘고 상태가 "충돌"로 표시됩니다. 디스코드는 답이 두 번 올 수 있는데 상태로는 알 수 없습니다("연결됨"으로 보임). PC 봇을 허브로 옮기려면 허브 화면의 **메신저** 창(또는 **설정 → 메신저**)에서 그 토큰을 넣고, PC 화면의 **설정 → 메신저**에서 그 봇의 "이 봇을 켭니다"를 끄고 저장합니다. 꺼 둔 봇은 PC의 메신저 창에서 고를 수 없습니다.
>
> 허용 목록은 PC와 허브가 따로입니다. 허브로 옮긴 봇은 허브 화면의 메신저 창에서 숫자로 다시 등록하거나, `/whoami`를 보낸 뒤 허브 화면의 **허용 요청**에서 허용합니다.

## 7. 카카오톡 연결

화면 왼쪽 아래 **메신저 → 카카오톡**을 고르면 스킬 URL이 나옵니다. **복사**를 누르고, 카카오 오픈빌더의 스킬 URL 칸에 붙여 넣어 저장합니다. 그다음 6절 4번처럼 화면의 숫자를 봇테스트에서 보내 주인으로 등록합니다. 같은 URL은 **설정 → 메신저 → 카카오 스킬 URL**에도 있습니다.

- PC 화면에서 복사하면 PC 완결형 경로, 허브 화면에서 복사하면 허브 경로입니다. **마지막에 붙여 넣은 쪽이 응답**합니다.
- 카카오 봇이 목록에 없으면 **설정 → 메신저**의 봇 추가에서 메신저 "카카오톡", 봇 ID `default`로 추가합니다.
- 숫자 대신 봇테스트에서 `/whoami`를 보낸 뒤 **허용 요청**에서 허용해도 됩니다.
- `/whoami`의 "봇 이름"으로 어느 쪽이 답했는지 구분할 수 있습니다(각 화면에서 정한 봇 이름).

## 8. 허브형으로 쓰기

1. **허브 처음 열기:** 허브 주소를 열면 **관리자 만들기**가 나옵니다. 비밀번호(10자 이상)를 두 번 넣습니다. 다음부터는 이 비밀번호로 로그인합니다. 로그인은 브라우저마다 따로 합니다.
2. **PC를 허브에 연결(가장 쉬운 방법):** 허브 화면에서 **설정 → 밖에서도 쓰기 → 링크 만들기**를 누릅니다. 나온 링크를 연결할 PC에서 엽니다(복사해서 그 PC의 브라우저 주소창에 붙여 넣기). PC 화면에 "이 PC를 허브에 연결할까요?"와 허브 주소가 나오면, **내가 만든 링크가 맞을 때만** **연결**을 누릅니다. 이 PC 이름은 비워 두면 컴퓨터 이름이 됩니다. 링크는 10분 동안 한 번만 쓸 수 있습니다.
   - **다른 방법(6자리 코드):** PC 화면 **설정 → 밖에서도 쓰기 → 허브에 연결**에 허브 주소를 넣고 **연결**을 누르면 6자리 코드가 나옵니다. 허브 화면 **설정 → 밖에서도 쓰기 → 연결 요청**에 같은 코드가 뜨면 **승인**합니다. 같은 PC를 다시 연결할 때는 "기존 기기 대체"를 고르면 세션 등록을 그대로 씁니다.
3. **접속 제한:** 허브 화면의 **설정 → 허브 보안·Codex**에서 허브를 열 수 있는 곳(내 IP·Cloudflare Access·Tailscale)을 정합니다. 지금 접속한 곳이 막히는 변경은 저장되지 않습니다.
4. **휴대폰에서 쓰기(선택):** 휴대폰 브라우저에서 허브 주소를 열고 로그인한 뒤 **홈 화면에 추가**를 합니다(Android Chrome은 "앱 설치"로 보일 수 있고, iPhone Safari는 공유 버튼에 있습니다). 앱처럼 아이콘이 생기고, 좁은 화면에서는 목록과 대화가 번갈아 보입니다. 허브는 3번에서 허용한 곳에서만 열립니다. 인터넷이 끊기면 화면을 쓸 수 없습니다(오프라인 저장 없음).

허브 화면의 대화 목록은 PC 이름별로 묶여 보입니다. 허브 화면에서 **＋ 대화 연결**을 누르면 **설정 → 대화**의 세션 등록으로 갑니다(허브는 PC의 대화 목록을 볼 수 없습니다). PC의 대화는 PC 화면에서 연결해 두는 것이 쉽습니다.

> **PC를 허브에 연결하면** 그 PC의 세션 질문은 허브를 거쳐서 실행됩니다. PC 화면에서는 질문을 받지 않고 "이 PC는 허브에 연결돼 있어요" 카드가 뜹니다(**허브 화면 열기**). 실제 답을 받으려면 **PC의 AI 응답**이 켜져 있어야 합니다(4절).

**허브에서 새 세션 쓰기(선택)**

1. ChatGPT 웹의 **설정 → 보안**에서 "Codex, Excel, PowerPoint 및 Word의 기기 코드 로그인 활성화"를 켭니다.
2. 허브 화면 **설정 → 허브 보안·Codex**에서 **로그인**을 누르면 주소와 코드가 나옵니다. 그 주소를 열어 코드를 넣고 승인합니다. "로그인됨"이 되면 1번 설정은 다시 꺼도 됩니다. 로그인이 풀리면 대화 안에 "허브의 Codex 로그인이 필요해요" 카드가 뜹니다.
3. 같은 탭의 **허브 새 세션 실제 실행 켜기**를 켜고, **설정 → 대화**의 새 세션에서 "새 세션 만들기를 켭니다"를 저장합니다.
4. 허브 화면 왼쪽 위 **＋ 새 세션**에서 엔진 Codex로 만듭니다(허브에 연결된 메신저 봇에서는 `/new codex <이름>`, 내 프로그램은 API `POST /v1/sessions`). 허브에서는 Codex만 쓸 수 있습니다.

## 9. 내 프로그램에서 쓰기 (API 키)

**설정 → 내 프로그램 연결**에서 프로그램 이름을 넣고 **키 발급**을 누릅니다. 키는 한 번만 보이니 그 프로그램 설정에 바로 넣고, 볼 수 있는 세션을 체크해 저장합니다. 필요 없어지면 **폐기**합니다. 사용법은 [API_GUIDE](API_GUIDE.md)를 보세요.

## 10. 끄기·다시 켜기·업데이트·지우기

| 하고 싶은 일 | 방법 |
| --- | --- |
| AI 호출만 멈추기 | 대화 위쪽 **AI 응답** 스위치 끄기(또는 **설정 → 이 PC**의 실제 실행 끄기). 이어온은 켜져 있어도 AI를 부르지 않습니다 |
| 허브 연결만 끊기 | PC 화면 **설정 → 밖에서도 쓰기**의 "연결 끊기". 다시 쓰려면 "다시 연결" |
| 이 PC와 허브의 짝을 없애기 | PC 화면 **설정 → 밖에서도 쓰기**의 "허브 잊기". 다시 쓰려면 8절 2번 |
| PC를 끄기 | 그냥 끄면 됩니다. 다음 로그온 때 자동으로 켜집니다 |
| 이어온을 완전히 끄기 | 이어온 폴더에서 아래 **끄기** 명령. 자동 시작도 함께 없어지고, 설정과 대화 기록은 남습니다 |
| 다시 켜기 | 이어온 폴더에서 아래 **켜기** 명령. 자동 시작도 다시 등록됩니다 |
| 새 버전으로 업데이트 | 새 버전 파일을 받은 뒤 **켜기** 명령. 설정과 토큰은 그대로이고, 부품이 바뀌었으면 자동으로 새로 설치한 뒤 새 코드로 다시 시작합니다(이때는 인터넷이 필요합니다) |
| 완전히 지우기 | **끄기** 명령 뒤에 이어온 폴더를 지웁니다. 설정과 대화 기록도 함께 사라집니다 |

끄기:

```powershell
pwsh scripts/install.ps1 -Uninstall
```

켜기:

```powershell
pwsh scripts/install.ps1
```

## 11. 문제가 있을 때

| 보이는 것 | 할 일 |
| --- | --- |
| 바로 가기를 열어도 화면이 안 나옴 | 10절의 **켜기** 명령을 실행(이미 설치돼 있으면 다시 시작만 함) |
| 바탕화면 아이콘이 브라우저 모양 | 바탕화면에서 F5(새로 고침). Edge가 없는 PC는 브라우저 탭으로 열리는 것이 정상입니다 |
| 봇이 "토큰 없음" | **메신저** 창에서 그 메신저를 골라 토큰 다시 넣기(여러 봇은 **설정 → 메신저**의 그 봇 토큰 칸) |
| 메신저에서 답이 없음 | 메신저 창의 6자리 숫자로 주인 등록, 또는 "허용 대기" 띠·**설정 → 메신저 → 허용 요청**에 내가 있으면 "허용" |
| "PC 연결 끊김" | 그 PC가 켜져 있는지, 허브형이면 PC 화면 **설정 → 밖에서도 쓰기**가 "연결됨"인지 확인 |
| "실제 실행이 꺼져 있음"·"AI 응답이 꺼져 있어요" | PC 세션은 PC 화면 위쪽 **AI 응답** 스위치(또는 카드의 **AI 응답 켜기**), 허브 새 세션은 허브의 **설정 → 허브 보안·Codex**에서 켜기 |
| "이 PC는 허브에 연결돼 있어요" | PC 화면에서는 보낼 수 없음. **허브 화면 열기**로 허브에서 보내기 |
| Codex 질문이 "사용 중"으로 거절 | Codex 앱에서 그 대화를 닫고 다시 보내기 |
| 허브 Codex 로그인에서 기기 코드가 꺼져 있다는 안내 | 8절의 ChatGPT 보안 설정을 켠 뒤 **로그인**을 다시 누르기 |

개발·문제 해결용 명령(`scripts/ieon.ps1`)은 [MANUAL](MANUAL.md) 부록에 있습니다. 보통은 쓸 일이 없습니다.
