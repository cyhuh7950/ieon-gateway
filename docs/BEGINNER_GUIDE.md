# 이어온 처음 쓰는 사람을 위한 따라 하기

기준: 2026-11-12(새 화면 U1~U8 반영, 처음 쓰는 사람 검토 반영). **설치는 한 번만 하고, 처음 한 번 대화 하나만 고르면 바로 쓸 수 있습니다. 나머지 설정은 화면의 설정(톱니)에서 합니다.** 내부 토큰을 만들거나 파일에 옮겨 적을 일은 없습니다.

이 설명서의 본문(1~7절)은 **내 PC 하나로 첫 답을 받는 길**입니다. 허브·여러 봇·내 프로그램 연결은 뒤의 **고급 사용**(8~10절)에 있습니다.

## 0. 먼저 알아 둘 것

### 이어온이란

이미 쓰고 있는 **Codex 대화**와 **Claude Code 세션**에 웹 화면·메신저(텔레그램·디스코드·슬랙·카카오톡)·내 프로그램에서 질문을 보내고 답을 받게 해 주는 도구입니다. 새 대화로 바꾸지 않고 **같은 대화를 이어서** 씁니다.

### 두 가지 쓰는 방법

| | **PC 완결형(ieon)** — 이 설명서 본문 | **허브형(ieun)** — 8절 |
| --- | --- | --- |
| 무엇을 켜 두나 | 내 PC 하나 | 공개 서버(허브) + 내 PC |
| 웹 화면 | 내 PC의 `http://127.0.0.1:28760` | 허브 주소(예: `https://ieun-gateway.sinsan.kr`) |
| PC가 꺼지면 | 봇이 답하지 않음 | 허브의 새 세션은 답하고, PC 세션만 "PC 연결 끊김" |

### 꼭 지킬 약속

- **AI 응답**(AI 호출)은 필요할 때만 켜고, 다 쓰면 끕니다(4절). 설치 직후에는 꺼져 있습니다.
- 업무용 중요한 대화는 연결하지 않습니다. **시험용 대화로 먼저** 해 보세요.
- 비밀번호·봇 토큰·API 키는 채팅이나 문서에 붙이지 않습니다.
- 결과를 확인할 수 없는 질문은 이어온이 **자동으로 다시 보내지 않습니다**(5절). 같은 일이 두 번 실행되지 않게 하기 위해서입니다.
- **같은 메신저 봇을 두 곳(PC와 허브)에서 동시에 켜지 않습니다**(9절).

## 1. 준비물과 설치 (한 번만)

### 1-1. 준비물 확인

| 준비물 | 확인 방법 | 없으면 |
| --- | --- | --- |
| Windows 11 | — | — |
| **PowerShell 7**(`pwsh`) | 시작 메뉴에서 "PowerShell"을 열고 `pwsh --version` 입력 → `PowerShell 7.…`이 나오면 됨 | 마이크로소프트 공식 안내 [Windows에 PowerShell 설치](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows)를 따라 설치(예: `winget install --id Microsoft.PowerShell --source winget`). Windows에 원래 있는 "Windows PowerShell 5.1"과는 다릅니다 |
| **Node.js 24** | `node --version` → `v24.…`이 나오면 됨 | [nodejs.org](https://nodejs.org)에서 24 버전 설치. 설치가 버전을 확인하고, 다르면 안내 후 멈춥니다 |
| 인터넷 | — | 처음 설치와 업데이트 때 부품을 받습니다 |
| **쓰려는 AI**(둘 중 하나 이상) | Codex: Codex 앱에 로그인돼 있음 / Claude Code: 터미널에서 `claude`가 실행되고 Pro·Max 구독 계정으로 로그인돼 있음 | 그 앱에서 평소처럼 설치·로그인. 로그인은 직접 합니다(이어온이 대신하지 않음) |

### 1-2. 이어온 받기

1. 이어온 파일을 받습니다. 관리자가 준 **압축 파일**이 있으면 그것을, 저장소 접근 권한이 있으면 저장소(`cyhuh7950/ieon-gateway`)의 **Code → Download ZIP**을 받습니다.
2. **지우지 않을 폴더**에 풉니다. 예: `C:\ieon-gateway`. 이 폴더 안에 이어온의 설정과 기록(`.local` 폴더)이 생기므로, 나중에 이 폴더를 지우면 이어온 기록도 함께 지워집니다(11절).

### 1-3. 설치

그 폴더에서 PowerShell 7을 엽니다(폴더에서 주소창에 `pwsh`를 입력하고 Enter). 그리고 **아래 한 줄**을 실행합니다.

```powershell
pwsh scripts/install.ps1
```

설치가 하는 일은 다음과 같습니다.

1. 부품 설치(인터넷 필요)
2. 설정과 내부 토큰 만들기(값은 보이지 않음)
3. 로그온할 때 창 없이 자동으로 시작하도록 등록
4. 지금 시작
5. 웹 화면 열기
6. 바탕화면에 **이어온** 바로 가기 만들기(Edge가 있으면 Edge 앱 창으로, 없으면 브라우저 탭으로 열림)

끝나면 "처음 한 번 대화 하나만 고르면 바로 쓸 수 있고, 나머지는 화면의 '설정'(톱니)에서 합니다"라는 안내가 나옵니다.

> 설치는 **AI 응답을 끈 채로** 시작합니다. 이 상태에서는 AI가 호출되지 않습니다.

## 2. 화면 열기

Windows에 로그온하면 이어온이 창 없이 자동으로 켜집니다. 바탕화면의 **이어온**을 엽니다. 이 PC에서 연 화면은 **자동으로 로그인**됩니다.

- **왼쪽:** 연결한 대화 목록(엔진, 상태 한 줄, 처리할 일 개수). 맨 위에 **＋ 대화 연결**, 왼쪽 아래에 **메신저**와 **설정**(⚙).
- **가운데:** 고른 대화. 위쪽에 대화 이름·상태, **AI 응답** 스위치, **연결 설정**. 문제가 있으면 대화 안에 이유와 버튼이 있는 카드가 뜹니다.
- **설정**(⚙)의 탭: 이 PC · 밖에서도 쓰기 · 메신저 · 대화 · 내 프로그램 연결(허브 화면에는 허브 보안·Codex). 위쪽 **← 대화로**를 누르면 돌아옵니다.

## 3. 이어 쓸 대화 연결하기

쓰는 AI에 따라 아래 중 하나를 따라 합니다.

### 3-A. Codex를 쓰는 경우

**처음 열면** 연결한 대화가 없으니 **처음 설정 3단계**가 자동으로 뜹니다.

1. **준비 확인:** 이 PC의 Codex 로그인 여부를 보여 줍니다. 로그인이 안 돼 있으면 Codex 앱에서 로그인한 뒤 계속합니다.
2. **대화 고르기:** 이 PC에서 최근에 쓴 Codex 대화 목록에서 하나를 누릅니다(10초쯤 걸립니다). **시험용 대화**를 고르세요.
3. **준비됐어요:** 메신저·허브는 나중에 해도 됩니다. **대화 열기**를 누릅니다.

닫았다가 다시 보려면 주소 끝에 `/#setup`을 붙여 엽니다.

- **대화를 더 연결할 때:** 왼쪽 위 **＋ 대화 연결** → 목록에서 고르기. 허용 목록 추가와 세션 등록이 한 번에 되고 그 대화가 바로 열립니다. 업무 대화는 목록에 나오지 않습니다.
- **목록에 없으면:** **＋ 대화 연결 → 고급: 대화 ID 직접 넣기**. 대화 ID는 파일 탐색기 주소창에 `%USERPROFILE%\.codex\sessions`를 넣어 열고, 날짜 폴더 안 `rollout-….jsonl` 파일 이름 끝부분입니다. 예: `rollout-2026-10-29T21-09-09-01a18790-63c7-73e3-a60b-6ddb60fd5be8.jsonl` → `01a18790-63c7-73e3-a60b-6ddb60fd5be8`
- **보낼 때 Codex 앱에서 그 대화를 열어 두지 마세요.** 열려 있으면 "사용 중"으로 거절됩니다(앱은 켜져 있어도 되고 그 대화만 닫으면 됩니다).

### 3-B. Claude Code를 쓰는 경우

Claude Code는 **이어온 채널을 켠 Claude Code 창이 열려 있는 동안만** 질문을 받습니다.

채널 준비(이어온 폴더 `.local\c1`의 연결 설정과 내부 열쇠)는 **설치(`install.ps1`)가 해 둡니다.** 따로 할 일은 없습니다. 예전에 설치한 PC는 1-3의 설치 명령을 한 번 다시 실행하면 빠진 준비만 보탭니다(있던 설정은 바꾸지 않음).

1. 이어온 폴더의 PowerShell 7에서 `pwsh scripts/ieon.ps1 claude`를 실행합니다. 새 창에서 Claude Code가 이어온 채널과 함께 시작됩니다.
   - 처음이면 그 창에서 `/login`으로 **구독 계정(Pro·Max)** 로그인을 직접 합니다. API 키 로그인은 쓰지 않습니다.
   - 처음 열 때 Claude Code가 이 폴더의 MCP 서버 `ieon`을 쓸지 묻거나, 개발용 채널을 불러온다는 안내를 보여 주면 **허용(계속)**을 고릅니다. 이어온 채널이 바로 이것입니다.
   - 창 아래쪽이 `manual mode`인지 확인합니다(`auto mode`면 `shift+tab`으로 끕니다).
   - 이 창에 질문을 직접 입력하지 않습니다(입력해도 이어온으로 답이 가지 않습니다). 끝낼 때 `/exit`.
2. 이어온 화면 **설정 → 대화 → 세션 등록**에서 아래처럼 넣고 **저장**합니다(처음 한 번).
   - ID: `c_`로 시작하는 이름(예: `c_claude`)
   - 이름: 목록에 보일 이름(예: "Claude 시험")
   - 엔진: **Claude 채널**, PC: 이 PC
   - 세션 ID: `ieon`
   - 보이는 곳: 웹(메신저에서도 쓰려면 "메신저 기본 봇"도)
3. 왼쪽 목록에 생긴 그 대화를 고릅니다. 상태가 "Claude 세션 꺼짐"이면 1번 창이 꺼져 있는 것입니다.

## 4. AI 응답 켜기·끄기

처음 질문을 보내면 "AI가 이 질문에 답해요" 확인 창이 뜹니다. **켜고 보내기**를 누르면 AI 응답이 켜지고 질문이 갑니다(취소하면 보내지 않습니다). 다 쓰면 대화 위쪽 **AI 응답** 스위치로 끕니다.

| 궁금한 점 | 답 |
| --- | --- |
| 고른 대화에만 적용되나요? | **아니요. 이 PC의 모든 대화(Codex·Claude 모두)에 함께 적용**됩니다. 이 PC 설정 파일에 저장되는 값 하나입니다 |
| 이어온·PC를 다시 켜도 유지되나요? | **유지됩니다.** 켠 채로 두면 재시작 뒤에도 켜져 있습니다 |
| 끄면 이미 진행 중인 질문도 멈추나요? | 스위치를 바꾸면 이 PC의 연결부가 새 설정으로 **다시 시작**합니다. 그때 처리 중이던 질문은 결과를 확인할 수 없게 될 수 있습니다("확인이 필요한 질문" 카드, 5절). 그래서 **처리 중이 아닐 때 끄세요.** 아직 시작 전이던 질문은 "실제 실행이 꺼져 있음"으로 실행되지 않습니다 |
| 어디서 바꾸나요? | **이 PC에서 연 화면에서만.** 휴대폰·허브 화면에서는 바꿀 수 없습니다. 메신저·내 프로그램에서 온 질문도 이 스위치가 켜져 있을 때만 답합니다 |

같은 스위치가 **설정 → 이 PC**의 "실제 실행 켜기"에도 있습니다.

## 5. 질문하기

왼쪽 목록에서 대화를 고르고 아래 입력창에 질문을 써서 **보내기**(Enter)를 누르면 답이 나옵니다. 줄을 바꾸려면 Shift+Enter. 진행 표시는 접수 → 실행 중 → 완료 순서입니다.

- **"확인이 필요한 질문" 카드:** 결과를 확인하지 못한 질문입니다. 원래 앱(Codex·Claude Code)에서 실행됐는지 보고 **실행됐어요** 또는 **실행되지 않았어요**를 누릅니다. 정리하기 전까지 그 대화는 잠깁니다. **자동으로 다시 보내지 않습니다.**
- **"보내지 못한 질문" 카드:** **다시 보내기**는 보내지 않은 것이 확실할 때만 나오고, 누를 때만 보냅니다.

여기까지 되면 **웹에서 첫 답 받기는 끝**입니다.

## 6. 메신저에서 첫 답 받기 (텔레그램·디스코드·슬랙)

이 세 메신저는 이어온이 메신저 서버로 먼저 접속하므로 **공개 주소가 필요 없습니다**.

1. 메신저에서 봇을 만들고 **봇 토큰**을 받습니다(텔레그램은 BotFather `/newbot`, 디스코드·슬랙은 개발자 화면 — [MESSENGER_MANUAL](MESSENGER_MANUAL.md) 4절).
2. 화면 왼쪽 아래 **메신저** → 메신저를 고릅니다.
3. 토큰을 칸에 붙여 넣고 **연결**(텔레그램·디스코드 1칸, 슬랙 2칸). 저장한 토큰은 다시 보이지 않습니다.
4. 봇이 연결되면 **6자리 숫자**가 크게 나옵니다. 메신저에서 그 봇에게 **숫자만** 보냅니다. "주인으로 등록됐어요"가 나오면 끝입니다.
   - 숫자는 10분 동안 한 번만 쓸 수 있고, 5번 틀리면 잠깁니다(**숫자 새로 받기**).
   - 숫자 대신, 봇에게 아무 말이나 보낸 뒤 대화 화면의 "허용 대기" 띠나 **설정 → 메신저 → 허용 요청**에서 **허용**을 눌러도 됩니다.
5. 메신저에서 `/sessions`로 세션 목록을 보고 `/use 1`처럼 고른 뒤 질문합니다. 4절의 AI 응답이 켜져 있어야 답이 옵니다.

## 7. 카카오톡

카카오톡은 **카카오가 우리 쪽 공개 HTTPS 주소로 메시지를 보내 주는 방식**이라, 다른 메신저와 달리 **공개 서버가 꼭 필요**합니다.

| 쓰는 방법 | 카카오가 보내는 곳 | 필요한 것 |
| --- | --- | --- |
| PC 완결형 | 공개 서버의 **카카오 중계** → 내 PC가 가져감 | 운영자가 공개 서버에 중계를 배포하고 그 연결 정보를 이 PC에 넣어 둔 경우만. 없으면 화면에 스킬 URL이 나오지 않습니다 |
| 허브형(8절) | 허브가 직접 받음 | 허브 |

공개 서버가 없으면 카카오톡은 건너뛰고 6절의 메신저를 쓰세요.

**카카오 쪽 준비(처음 한 번, 카카오 계정 주인이 직접)**

1. **카카오톡 채널**을 만듭니다(카카오톡 채널 관리자센터). 실제 공개 서비스로 쓰려면 비즈니스 채널 인증이 필요할 수 있습니다.
2. **카카오 i 오픈빌더**에서 봇을 만들고 그 채널을 연결합니다.
3. 오픈빌더에서 **AI 챗봇 콜백** 기능을 신청해 승인받습니다. AI 답은 오래 걸려서, 카카오의 5초 응답 제한 안에 "접수"만 답하고 실제 답은 콜백으로 보내기 때문입니다. 승인 전에는 답이 오지 않습니다.
4. 이어온 화면 왼쪽 아래 **메신저 → 카카오톡**에서 **스킬 URL**을 **복사**합니다(같은 값이 **설정 → 메신저 → 카카오 스킬 URL**에도 있습니다). 이 주소에는 비밀 값이 들어 있으니 다른 곳에 올리지 마세요.
5. 오픈빌더 **스킬**에서 새 스킬을 만들고 URL 칸에 붙여 넣어 저장합니다.
6. 오픈빌더 **시나리오 → 폴백 블록**(모든 말을 받는 블록)에서 응답을 **스킬 데이터**로 바꿔 5번 스킬을 연결하고, **콜백 사용**을 켜서 저장합니다. 켜지 않으면 봇이 "AI 챗봇 콜백이 켜져 있지 않다"고 답합니다.
7. 오픈빌더 **봇 테스트**에서 이어온 화면의 6자리 숫자를 보내 주인으로 등록하고, `/whoami`·`/sessions`·질문 순서로 확인합니다.
8. 확인되면 오픈빌더에서 **배포**합니다. 배포해야 실제 카카오톡 채널 대화에서 답합니다.

- PC 화면에서 복사한 URL은 PC 완결형 경로, 허브 화면에서 복사한 URL은 허브 경로입니다. **오픈빌더에 마지막에 붙여 넣은 쪽이 응답**합니다.
- 카카오 봇이 목록에 없으면 **설정 → 메신저**의 봇 추가에서 메신저 "카카오톡", 봇 ID `default`로 추가합니다.
- `/whoami`의 "봇 이름"으로 어느 쪽(PC·허브)이 답했는지 구분할 수 있습니다.
- 메뉴 이름은 카카오 화면 개편에 따라 조금 다를 수 있습니다.

# 고급 사용

## 8. 고급: 허브형으로 쓰기

1. **허브 처음 열기:** 허브 주소를 열면 **관리자 만들기**가 나옵니다. 비밀번호(10자 이상)를 두 번 넣습니다. 다음부터는 이 비밀번호로 로그인합니다(브라우저마다 따로).
2. **PC를 허브에 연결(가장 쉬운 방법):** 허브 화면 **설정 → 밖에서도 쓰기 → 링크 만들기** → 나온 링크를 연결할 PC의 브라우저에서 엽니다. "이 PC를 허브에 연결할까요?"와 허브 주소가 나오면 **내가 만든 링크가 맞을 때만** **연결**. 링크는 10분 동안 한 번만 쓸 수 있습니다.
   - **다른 방법(6자리 코드):** PC 화면 **설정 → 밖에서도 쓰기 → 허브에 연결**에 허브 주소를 넣고 **연결** → 6자리 코드 → 허브 화면 **설정 → 밖에서도 쓰기 → 연결 요청**에서 같은 코드면 **승인**. 같은 PC를 다시 연결할 때는 "기존 기기 대체".
3. **접속 제한:** 허브 화면 **설정 → 허브 보안·Codex**에서 허브를 열 수 있는 곳(내 IP·Cloudflare Access·Tailscale)을 정합니다. 지금 접속한 곳이 막히는 변경은 저장되지 않습니다.
4. **휴대폰에서 쓰기(선택):** 휴대폰 브라우저에서 허브 주소를 열고 로그인한 뒤 **홈 화면에 추가**(Android Chrome은 "앱 설치", iPhone Safari는 공유 버튼). 허브는 3번에서 허용한 곳에서만 열리고, 인터넷이 끊기면 쓸 수 없습니다.

- 허브 화면의 대화 목록은 PC 이름별로 묶입니다. PC의 대화는 PC 화면에서 연결해 두는 것이 쉽습니다(허브는 PC의 대화 목록을 볼 수 없음).
- **PC를 허브에 연결하면** PC 화면에서는 질문을 받지 않고 "이 PC는 허브에 연결돼 있어요" 카드가 뜹니다(**허브 화면 열기**). 실제 답을 받으려면 **PC의 AI 응답**이 켜져 있어야 합니다(4절).

**허브에서 새 세션 쓰기(선택)**

1. ChatGPT 웹 **설정 → 보안**에서 "Codex, Excel, PowerPoint 및 Word의 기기 코드 로그인 활성화"를 켭니다.
2. 허브 화면 **설정 → 허브 보안·Codex → 로그인** → 나온 주소를 열어 코드를 넣고 승인. "로그인됨"이 되면 1번 설정은 다시 꺼도 됩니다.
3. 같은 탭의 **허브 새 세션 실제 실행 켜기**를 켜고, **설정 → 대화**의 새 세션에서 "새 세션 만들기를 켭니다"를 저장합니다.
4. 허브 화면 왼쪽 위 **＋ 새 세션**에서 엔진 Codex로 만듭니다(허브 메신저 봇에서는 `/new codex <이름>`). 허브에서는 Codex만 쓸 수 있습니다.

## 9. 고급: 메신저 봇을 PC에서 허브로 옮기기

**같은 봇을 PC와 허브에서 동시에 켜면** 텔레그램·슬랙은 메시지가 나뉘고 상태가 "충돌"로 보이며, 디스코드는 답이 두 번 올 수 있습니다(상태로는 "연결됨"으로 보여 알기 어려움). **허브에 토큰을 넣으면 그 봇은 1분 안에 바로 켜집니다.** 그래서 반드시 아래 순서로 합니다.

1. **PC에서 끄기:** PC 화면 **설정 → 메신저** → 그 봇을 눌러 편집 칸의 "이 봇을 켭니다"를 끄고 **저장**합니다.
2. **꺼진 것 확인:** 1분쯤 뒤 PC 화면 **메신저** 창을 엽니다. 그 메신저가 "꺼져 있음"으로 고를 수 없게 보이면 꺼진 것입니다.
3. **허브에 넣기:** 허브 화면 **메신저** 창에서 그 메신저를 고르고 같은 토큰을 넣어 **연결**합니다.
4. **연결 확인:** 허브 메신저 창에 숫자가 나오면(=연결됨) 그 숫자를 봇에게 보내 주인으로 등록합니다. 허용 목록은 PC와 허브가 따로라 허브에서 다시 등록해야 합니다.
5. **시험:** 봇에게 `/whoami`를 보내 "봇 이름"이 허브에서 정한 이름인지 확인하고, `/sessions` → `/use` → 짧은 질문으로 답이 오는지 봅니다.

되돌리려면 반대로 **허브에서 먼저 끄고**(허브 **설정 → 메신저**에서 "이 봇을 켭니다" 끄기) 확인한 뒤 PC에서 켭니다. 봇 이름·여러 봇·역할·허용 사용자는 **설정 → 메신저**에서 합니다([MESSENGER_MANUAL](MESSENGER_MANUAL.md)).

## 10. 고급: 내 프로그램에서 쓰기 (API 키)

**설정 → 내 프로그램 연결**에서 프로그램 이름을 넣고 **키 발급**을 누릅니다. 키는 한 번만 보이니 그 프로그램 설정에 바로 넣고, 볼 수 있는 세션을 체크해 저장합니다. 필요 없어지면 **폐기**합니다. 사용법은 [API_GUIDE](API_GUIDE.md)를 보세요.

## 12. 문제가 있을 때

| 보이는 것 | 할 일 |
| --- | --- |
| `pwsh`를 찾을 수 없다고 나옴 | PowerShell 7이 없습니다. 1-1의 공식 안내로 설치 |
| 설치가 "Node.js 24가 필요합니다"로 멈춤 | nodejs.org에서 24를 설치한 뒤 다시 실행 |
| 바로 가기를 열어도 화면이 안 나옴 | 11절의 **켜기** 명령(이미 설치돼 있으면 다시 시작만 함) |
| 바탕화면 아이콘이 브라우저 모양 | 바탕화면에서 F5. Edge가 없는 PC는 브라우저 탭으로 열리는 것이 정상 |
| 처음 설정 1단계에서 Codex "로그인 필요" | Codex 앱에서 로그인한 뒤 다시 확인 |
| 대화 목록이 비어 있음 | Codex 앱에서 대화를 한 번 이상 쓴 적이 있는지 확인, 또는 3-A의 "대화 ID 직접 넣기" |
| "Claude 세션 꺼짐" | 3-B 1번의 Claude Code 창이 열려 있는지 확인. 예전에 설치한 PC면 설치 명령을 한 번 다시 실행(채널 준비를 보탬) |
| Codex 질문이 "사용 중"으로 거절 | Codex 앱에서 그 대화를 닫고 다시 보내기 |
| "실제 실행이 꺼져 있음"·"AI 응답이 꺼져 있어요" | PC 화면 위쪽 **AI 응답** 스위치(또는 카드의 **AI 응답 켜기**). 허브 새 세션은 허브의 **설정 → 허브 보안·Codex** |
| 봇이 "토큰 없음" | **메신저** 창에서 그 메신저를 골라 토큰 다시 넣기 |
| 메신저에서 답이 없음 | 6절 4번의 숫자로 주인 등록, AI 응답이 켜져 있는지 확인 |
| 봇 상태가 "충돌" / 답이 두 번 옴 | 같은 봇이 두 곳에서 켜져 있음 → 9절 순서로 한쪽 끄기 |
| 카카오 "AI 챗봇 콜백이 켜져 있지 않아" | 7절 6번: 폴백 블록에서 콜백 사용 켜기 |
| 메신저 창에 카카오 스킬 URL이 안 나옴 | 이 PC에 카카오 중계가 준비돼 있지 않음(7절 표) |
| "PC 연결 끊김" | 그 PC가 켜져 있는지, 허브형이면 PC 화면 **설정 → 밖에서도 쓰기**가 "연결됨"인지 확인 |
| "이 PC는 허브에 연결돼 있어요" | PC 화면에서는 보낼 수 없음. **허브 화면 열기**로 허브에서 보내기 |
| 허브 Codex 로그인에서 기기 코드가 꺼져 있다는 안내 | 8절의 ChatGPT 보안 설정을 켠 뒤 **로그인**을 다시 누르기 |

개발·문제 해결용 명령(`scripts/ieon.ps1`)은 [MANUAL](MANUAL.md) 부록에 있습니다. 보통은 쓸 일이 없습니다.
