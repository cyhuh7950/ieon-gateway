## 0. 먼저 알아 둘 것

### 이어온이란

이미 쓰고 있는 **Codex 대화**와 **Claude Code 세션**에 웹 화면·메신저(텔레그램·디스코드·슬랙·카카오톡)·내 프로그램에서 질문을 보내고 답을 받게 해 주는 도구입니다. 새 대화로 바꾸지 않고 **같은 대화를 이어서** 씁니다.

### 두 가지 쓰는 방법

| | **PC 완결형(ieon)** | **허브형(ieun)** |
| --- | --- | --- |
| 무엇을 켜 두나 | 내 PC 하나 | 공개 서버(허브) + 내 PC |
| 웹 화면 | 내 PC의 `http://127.0.0.1:28760` | 허브 주소(예: `https://ieun-gateway.sinsan.kr`) |
| PC가 꺼지면 | 봇이 답하지 않음 | 허브의 새 세션은 답하고, PC 세션만 "PC 연결 끊김" |

처음에는 PC 완결형으로 시작하고, 필요할 때 8절의 "허브에 연결"을 하면 됩니다.

### 꼭 지킬 약속

- **실제 실행**(AI 호출)은 필요할 때만 켜고, 다 쓰면 끕니다(4절).
- 업무용 중요한 대화는 허용 목록에 넣지 않습니다. 시험용 대화로 먼저 해 보세요.
- 비밀번호·봇 토큰·API 키는 채팅이나 문서에 붙이지 않습니다.

## 1. 설치 (한 번만)

**준비물**

- Windows 11
- [Node.js 24](https://nodejs.org)
- 쓰려는 AI 앱(Codex 앱 또는 Claude Code). 로그인은 그 앱에서 평소처럼 해 둡니다.

**설치**

1. 이어온 폴더를 받습니다(관리자가 준 압축 파일을 풀거나 저장소를 내려받기).
2. 그 폴더에서 PowerShell을 열고 **아래 한 줄**을 실행합니다.

```powershell
pwsh scripts/install.ps1
```

설치가 하는 일은 다음과 같습니다.

1. 부품 설치
2. 설정과 내부 토큰 만들기(값은 보이지 않음)
3. 로그온할 때 창 없이 자동으로 시작하도록 등록
4. 지금 시작
5. 브라우저로 웹 화면 열기
6. 바탕화면에 **이어온** 바로 가기 만들기

> 설치는 **실제 실행을 끈 채로** 시작합니다. 이 상태에서는 AI가 호출되지 않습니다.

## 2. 시작하고 화면 열기

**시작:** 따로 할 일이 없습니다. Windows에 로그온하면 이어온이 창 없이 자동으로 켜지고, 메신저 봇도 함께 켜집니다.

**화면 열기:** 바탕화면의 **이어온**을 엽니다. 이 PC에서 연 화면은 **자동으로 로그인**됩니다. 위쪽 제목 옆에 지금 화면이 어느 쪽인지 표시됩니다("이 PC" 또는 "허브 · 주소").

위쪽 버튼은 두 개입니다.

- **세션**: 질문하는 곳
- **봇 관리**: 모든 설정. 아래 탭으로 나뉘어 있습니다.

| 탭 | 하는 일 | 보이는 곳 |
| --- | --- | --- |
| 이 PC | 실제 실행 켜기·끄기, Codex 허용 목록, 허브에 연결 | PC 화면 |
| 봇 | 봇 목록·추가, 봇 토큰, 부르는 이름 | 둘 다 |
| 메신저·카카오 | 허용 요청, 허용 사용자, 카카오 스킬 URL | 둘 다 |
| 세션 등록 | 기존 Codex·Claude 세션 등록 | 둘 다 |
| 새 세션 | 새 세션 기능 켜기, 한도, 정리 시간 | 둘 다 |
| 역할 | 봇 역할 정하기 | 둘 다 |
| 기기 | 연결된 PC 목록, 연결 요청 승인, 폐기 | 둘 다(승인은 허브) |
| 허브 보안·Codex | 허브 접속 제한, 허브 Codex 로그인 | 허브 화면 |
| 외부 프로그램 | API 키 발급·폐기 | 둘 다 |

저장 결과는 화면 위쪽에 잠깐 떠서 알려 줍니다.

## 3. 이어 쓸 Codex 대화 등록하기

**대화 ID 찾기:** 파일 탐색기 주소창에 `%USERPROFILE%\.codex\sessions`를 넣어 엽니다. 날짜 폴더 안의 `rollout-….jsonl` 파일 이름 끝부분이 대화 ID입니다.

예: `rollout-2026-10-29T21-09-09-01a18790-63c7-73e3-a60b-6ddb60fd5be8.jsonl` → `01a18790-63c7-73e3-a60b-6ddb60fd5be8`

**등록 (두 곳에 넣습니다)**

1. **봇 관리 → 이 PC 탭 → 허용 목록에 추가**
   - **Codex 대화 ID**
   - **연결 방식**: 보통 "번갈아 쓰기"(이어온으로 보낼 때 Codex 앱에서 그 대화를 닫아 두기)
   - **작업 폴더**(선택): 그 대화가 작업하는 폴더의 전체 경로
2. **봇 관리 → 세션 등록 탭**에서 ID(`c_`로 시작), 이름, 엔진 "Codex 대화", 세션 ID(위 대화 ID)를 넣고 저장합니다.

## 4. 실제 실행 켜기·끄기

**봇 관리 → 이 PC 탭 → "실제 실행 켜기"**를 체크하면 확인 창이 뜨고, 확인하면 그때부터 질문마다 AI가 호출됩니다. 다 쓰면 체크를 끕니다.

이 스위치는 **이 PC에서 연 화면에서만** 바꿀 수 있습니다. 휴대폰이나 허브 화면에서는 바꿀 수 없습니다.

## 5. 질문하기

**세션** 탭에서 세션을 고르고 질문을 보내면 답이 아래에 나옵니다.

상태 문구가 "확인 필요"면 원래 앱(Codex·Claude Code)에서 실행됐는지 보고 화면의 버튼으로 정리합니다. 자동으로 다시 보내지 않습니다.

**Claude Code 세션**은 Claude Code를 이어온 채널과 함께 켜 둔 동안만 받습니다. 사용법은 [MANUAL](MANUAL.md)의 "Claude 채널 세션"을 보세요.

## 6. 메신저 봇 연결

1. 메신저에서 봇을 만들고 **봇 토큰**을 받습니다(텔레그램은 BotFather, 디스코드·슬랙은 개발자 화면 — [MESSENGER_MANUAL](MESSENGER_MANUAL.md) 4절).
2. **봇 관리 → 봇 탭**에서 그 메신저의 봇(처음엔 `default`)을 고르고, 편집 칸의 **토큰**에 붙여 넣고 저장합니다. 1분 안에 "연결됨"이 됩니다. 저장한 토큰은 다시 보이지 않습니다.
3. 메신저에서 봇에게 아무 말이나 보낸 뒤, **봇 관리 → 메신저·카카오 탭 → 허용 요청**에 내 이름이 뜨면 **허용**을 누릅니다.
4. 메신저에서 `/sessions`로 세션 목록을 보고 `/use 1`처럼 골라 질문합니다.

> 같은 봇 토큰을 PC와 허브에 동시에 넣지 않습니다. 두 곳이 같은 봇을 받으면 메시지가 나뉩니다.

## 7. 카카오톡 연결

**봇 관리 → 메신저·카카오 탭 → 카카오 스킬 URL**에서 **복사**를 누르고, 카카오 오픈빌더의 스킬 URL 칸에 붙여 넣어 저장합니다.

- PC 화면에서 복사하면 PC 완결형 경로, 허브 화면에서 복사하면 허브 경로입니다. **마지막에 붙여 넣은 쪽이 응답**합니다.
- 카카오 봇이 목록에 없으면 **봇 탭**에서 메신저 "카카오톡", 봇 ID `default`로 추가합니다.
- 처음이면 봇테스트에서 `/whoami`를 보낸 뒤 **허용 요청**에서 허용합니다.
- `/whoami`의 "봇 이름"으로 어느 쪽이 답했는지 구분할 수 있습니다(각 화면에서 정한 봇 이름).

## 8. 허브형으로 쓰기

1. **허브 처음 열기:** 허브 주소를 열면 **관리자 만들기**가 나옵니다. 비밀번호(10자 이상)를 두 번 넣습니다. 다음부터는 이 비밀번호로 로그인합니다. 로그인은 브라우저마다 따로 합니다.
2. **PC를 허브에 연결:** 내 PC 화면의 **봇 관리 → 이 PC 탭 → 허브에 연결**에 허브 주소와 이 PC 이름을 넣고 "연결"을 누르면 6자리 코드가 나옵니다.
3. **허브에서 승인:** 허브 화면의 **봇 관리 → 기기 탭 → 연결 요청**에 같은 코드가 뜨면 **승인**합니다. 같은 PC를 다시 연결할 때는 "기존 기기 대체"를 고르면 세션 등록을 그대로 씁니다.
4. **접속 제한:** 허브 화면의 **봇 관리 → 허브 보안·Codex 탭**에서 허브를 열 수 있는 곳(내 IP·Cloudflare Access·Tailscale)을 정합니다. 지금 접속한 곳이 막히는 변경은 저장되지 않습니다.

> **PC를 허브에 연결하면** 그 PC의 세션 질문은 허브를 거쳐서 실행됩니다. PC 화면에서 직접 보낸 질문은 처리되지 않습니다. 실제 답을 받으려면 **PC 화면의 실제 실행**이 켜져 있어야 합니다(4절).

**허브에서 새 세션 쓰기(선택)**

1. ChatGPT 웹의 **설정 → 보안**에서 "Codex, Excel, PowerPoint 및 Word의 기기 코드 로그인 활성화"를 켭니다.
2. 허브 화면 **허브 보안·Codex 탭**에서 **로그인**을 누르면 주소와 코드가 나옵니다. 그 주소를 열어 코드를 넣고 승인합니다. "로그인됨"이 되면 1번 설정은 다시 꺼도 됩니다.
3. 같은 탭의 **허브 새 세션 실제 실행 켜기**를 켜고, **새 세션 탭**에서 "새 세션 만들기를 켭니다"를 저장합니다.
4. 왼쪽 **새 세션 만들기**에서 Codex 세션을 만듭니다. 허브에서는 Codex만 쓸 수 있습니다.

## 9. 내 프로그램에서 쓰기 (API 키)

**봇 관리 → 외부 프로그램 탭**에서 프로그램 이름을 넣고 **키 발급**을 누릅니다. 키는 한 번만 보이니 그 프로그램 설정에 바로 넣고, 볼 수 있는 세션을 체크해 저장합니다. 필요 없어지면 **폐기**합니다. 사용법은 [API_GUIDE](API_GUIDE.md)를 보세요.

## 10. 끄기·다시 켜기·업데이트·지우기

| 하고 싶은 일 | 방법 |
| --- | --- |
| AI 호출만 멈추기 | **이 PC 탭**의 실제 실행 끄기. 이어온은 켜져 있어도 AI를 부르지 않습니다 |
| 허브 연결만 끊기 | **이 PC 탭**의 "연결 끊기". 다시 쓰려면 "다시 연결" |
| 이 PC와 허브의 짝을 없애기 | **이 PC 탭**의 "허브 잊기". 다시 쓰려면 8절 2~3번 |
| PC를 끄기 | 그냥 끄면 됩니다. 다음 로그온 때 자동으로 켜집니다 |
| 이어온을 완전히 끄기 | 이어온 폴더에서 아래 **끄기** 명령. 자동 시작도 함께 없어지고, 설정과 대화 기록은 남습니다 |
| 다시 켜기 | 이어온 폴더에서 아래 **켜기** 명령. 자동 시작도 다시 등록됩니다 |
| 새 버전으로 업데이트 | 새 버전 파일을 받은 뒤 **켜기** 명령. 설정과 토큰은 그대로이고 새 코드로 다시 시작합니다 |
| 완전히 지우기 | **끄기** 명령 뒤에 이어온 폴더를 지웁니다. 설정과 대화 기록도 함께 사라집니다 |

끄기:

```powershell
pwsh scripts/install.ps1 -Uninstall
```

켜기:

```powershell
pwsh scripts/install.ps1
```

## 11. 문제가 있을 때

| 보이는 것 | 할 일 |
| --- | --- |
| 바로 가기를 열어도 화면이 안 나옴 | 10절의 **켜기** 명령을 실행(이미 설치돼 있으면 다시 시작만 함) |
| 바탕화면 아이콘이 브라우저 모양 | 바탕화면에서 F5(새로 고침) |
| 봇이 "토큰 없음" | **봇 탭**에서 그 봇의 토큰 칸에 다시 넣기 |
| 메신저에서 답이 없음 | **메신저·카카오 탭 → 허용 요청**에 내가 있으면 "허용" |
| "PC 연결 끊김" | 그 PC가 켜져 있는지, PC 화면 **이 PC 탭**이 "연결됨"인지 확인 |
| "실제 실행이 꺼져 있음" | PC 세션은 **이 PC 탭**, 허브 새 세션은 허브의 **허브 보안·Codex 탭**에서 켜기 |
| Codex 질문이 "사용 중"으로 거절 | Codex 앱에서 그 대화를 닫고 다시 보내기 |
| 허브 Codex 로그인에서 기기 코드가 꺼져 있다는 안내 | 8절의 ChatGPT 보안 설정을 켠 뒤 **로그인**을 다시 누르기 |

개발·문제 해결용 명령(`scripts/ieon.ps1`)은 [MANUAL](MANUAL.md) 부록에 있습니다. 보통은 쓸 일이 없습니다.
