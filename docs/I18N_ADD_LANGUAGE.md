# 새 언어 더하기 — 이어온

이어온 화면·앱·메신저 봇에 새 언어(예: 일본어 `ja`)를 더하는 순서입니다. **코드는 고치지 않습니다** — 사전 폴더를 하나 더하고 복사 도구를 한 번 돌리면 됩니다. 설계: [design/I18N.md](design/I18N.md) 5절 I18N-c.

## 0. 먼저 알아 둘 것

- 사전은 저장소 맨 위 `locales/<언어>/<묶음>.json`입니다. 묶음은 7개 — `common`(공통 낱말), `errors`(오류 문구), `messenger`(봇 답), `server`(서버가 만드는 글), `web`(대화 화면), `settings`(설정 화면), `app`(이어온 앱).
- 한국어(`ko`)가 원본, 영어(`en`)가 기준 번역입니다. 새 언어 사전에 없는 키는 **영어 → 한국어** 순으로 대신 보여서, 일부만 번역해도 화면이 깨지지 않습니다.
- 언어 이름은 `ko`, `en`, `ja`, `zh-TW`처럼 2~3자 언어 코드(필요하면 `-지역`)로 씁니다. 이 폴더 이름이 그대로 언어 코드가 됩니다.

## 1. 영어 사전을 복사한다

```powershell
Copy-Item -Recurse locales\en locales\ja
```

## 2. 번역한다

`locales/ja/*.json`의 **값만** 그 언어로 바꿉니다. 키는 바꾸거나 지우지 않습니다.

| 지킬 것 | 예 |
| --- | --- |
| `{이름}` 자리 표시는 같은 이름 그대로(순서는 그 언어 어순대로) | `"{name} replied"` → `"{name}が返信しました"` |
| 영어 단수·복수가 필요하면 `{count\|one:…\|other:…}` 꼴(`#` = 그 수) | 대개는 필요 없음 |
| HTML 조각(`<b>` 등)·`\n`·명령어(`/sessions`)·코드·경로는 그대로 | |
| 사용자 질문·AI 답·대화 이름·AI 직원 이름은 사전에 없음(번역 대상 아님) | |

**꼭 바꿔야 하는 특별한 값**(그 언어에 맞게):

| 키 | 뜻 | 일본어 예 |
| --- | --- | --- |
| `common.lang_name` | 언어 고르기 칸에 보이는 이름(그 언어로) | `日本語` |
| `common.intl_locale` | 날짜·숫자 형식 | `ja-JP` |
| `common.speech_lang` | 받아쓰기·읽어 주기 언어 | `ja-JP` |
| `messenger.alias.allow` … `confirm` | 봇에서 쓰는 명령 별칭(영어 명령 `/allow` 등은 늘 같이 받음) | `許可` 등 |
| `messenger.call_suffixes` | 봇을 부를 때 이름 뒤에 붙는 말(`\|`로 구분, 없으면 빈 값) | `""` |
| `settings.danger.start`·`settings.danger.end` | 이 낱말로 시작·끝나는 버튼은 빨간 "되돌릴 수 없는 일" 버튼(정규식 `\|` 목록) | `削除\|解除` 등 |

번역은 AI에게 맡겨도 됩니다. 영어 번역 때 쓴 용어표·지침을 같이 주면 일관됩니다.

## 3. 앱 사전을 복사한다

이어온 앱(휴대폰·PC)은 사전을 앱 안으로 복사해 씁니다. 앱을 빌드할 때 자동으로 돌지만(`npm run build`의 `prebuild`), 시험이 복사본이 맞는지 보므로 한 번 돌려 함께 커밋합니다.

```powershell
node app/scripts/copy-locales.mjs
```

이 도구가 함께 만드는 것: `app/src/locales/<언어>.json`·`index.ts`(앱 사전), `app/electron/locales.json`(PC 앱 창 제목·메뉴), `app/android/.../res/values-<언어>/strings.xml`(안드로이드 앱 이름).

## 4. 시험을 돌린다

```powershell
node --test --test-timeout=60000 tests/pilot/*.test.mjs tests/relay/*.test.mjs
```

| 시험 | 새 언어에서 보는 것 |
| --- | --- |
| 키 맞춤 | 한국어에 없는 키가 있으면 실패. 빠진 키는 실패가 아니라 개수만 알림(`[I18N] ja: 빠진 키 N개(영어로 보임)`) |
| 채우기 맞춤 | `{이름}` 자리 표시가 한국어와 다르면 실패 |
| 앱 사전 | 3번을 안 했으면 실패 |

## 5. 확인한다

- 웹: 화면 맨 위(설정)·로그인 화면 아래 언어 칸에 새 언어가 보이고, 고르면 화면이 바뀝니다. 브라우저 언어가 그 언어면 처음부터 그 언어로 나옵니다.
- 앱: 연결 화면·목록 아래 언어 칸, 또는 기기 언어.
- 메신저: 설정 → 관리 → 대화 등록의 "서버 언어", 또는 봇마다 "답 언어".
- 넘침 점검(선택): 가짜 언어로 화면이 넘치는 곳을 찾는 방법은 [tools/video/README.md](../tools/video/README.md) "화면 점검".

## 6. (선택) 문서

- 설명서: `docs/en/`을 `docs/<언어>/`로 복사해 번역. 맨 첫 줄 `<!-- source: docs/<원본> @ <커밋> -->`를 남기면 원본이 바뀐 것을 알 수 있습니다.
- 처리방침·약관: `src/pilot/web/privacy.<언어>.html`·`terms.<언어>.html`을 두면 `/privacy`·`/terms`가 그 언어로 열립니다(법적 문서는 원어민·전문가 검토 권장).
- PC 설치 파일의 설치 화면 언어: `app/package.json`의 `build.nsis.installerLanguages`에 그 언어(예: `ja_JP`)를 더합니다.

## 바꾸지 않아도 되는 것

서버·웹 화면·앱·메신저 코드, 언어 목록(폴더를 읽어 자동), 언어 고르기 칸, 날짜·음성 처리 — 모두 사전을 따라갑니다. 2026-11-20에 시험용 언어로 이 순서를 그대로 해 보고(코드 변경 없이 언어 칸·화면·앱 사전·안드로이드 이름까지 나옴) 되돌렸습니다.
