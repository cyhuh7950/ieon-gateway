## 2. 자세한 설명(4000자 이내)

```
이어온은 내 PC에서 돌아가는 AI 작업 세션(Codex, Claude Code 등)을 휴대폰과 PC에서 이어서 쓰게 해 주는 앱입니다.

■ 같은 세션을 그대로 이어서
새 대화를 만드는 것이 아니라, PC에서 하던 그 작업 세션에 질문을 보내고 답을 받습니다.

■ AI 직원과 방
세션마다 이름과 아이콘을 붙여 "AI 직원"처럼 부르고, 여러 AI 직원을 한 방에 모아 @이름으로 부를 수 있습니다. 한 직원의 답을 다른 직원에게 넘길 수도 있습니다.

■ 허락은 버튼으로
AI가 파일을 고치거나 명령을 실행하려 하면 앱에 허락 카드가 뜹니다. 허용/거부 버튼으로만 정하고, 15분 안에 답하지 않으면 거부됩니다.

■ 말로 묻고 소리로 듣기
기기에 들어 있는 받아쓰기·읽어 주기 기능으로 말로 질문하고 답을 들을 수 있습니다(받아쓴 글은 고친 뒤 보냅니다).

■ 내 서버에만 저장
질문과 답은 내가 설치한 이어온 서버(내 PC 또는 내 허브)에만 저장됩니다. 회원 가입·광고·이용 분석이 없습니다.

※ 이어온 앱을 쓰려면 PC에 이어온 프로그램을 먼저 설치하고, 웹 화면에서 만든 연결 코드로 앱을 연결해야 합니다.
```

## 3. 데이터 보안(Data safety) 답

| 질문 | 답 | 근거 |
| --- | --- | --- |
| 사용자 데이터를 수집하거나 공유하나요? | **수집함, 공유 안 함** | 질문·답은 사용자가 연결한 사용자 소유 서버로만 전송. 개발자 서버 없음 |
| 전송 중 암호화 | 예(허브 https). PC형을 Tailscale http로 쓰는 경우는 Tailscale 암호화 | |
| 삭제 요청 방법 | 앱 안 "이 기기 연결 끊기", "이 대화의 서버 보관 기록 지우기", 처리방침 5절 | |
| 수집 항목 | 메시지(앱 내 메시지 — 질문·답), 기기 ID 등(기기 이름·알림 주소) | 앱 기능용, 선택 아님 |
| 위치·연락처·사진·금융·건강 | 수집 안 함 | 권한 없음 |
| 음성 | 수집 안 함(기기 받아쓰기 창이 처리, 앱은 마이크 권한 없음) | |

> 주의: 구글 기준의 "수집"은 앱에서 기기 밖으로 나가는 것을 말한다. 받는 곳이 사용자 본인 서버여도 "수집함"으로 답하는 편이 안전하다(심사 반려 방지).

## 4. 콘텐츠 등급·대상

- 대상 연령: 18세 이상(개발자 도구), 아동 대상 아님.
- 사용자 생성 콘텐츠: AI 답이 화면에 나옴 → 설문에서 "사용자 간 공유 없음"(다른 사용자와 대화 기능 없음).

## 5. 심사용 안내(필수 — AP-5 전에 준비할 것)

심사자가 앱을 열면 "서버 주소 + 연결 코드"가 필요하다. **심사용 시험 허브**를 따로 두고, 시험 대화(가짜 답을 주는 시험 PC 또는 실제 시험 세션)를 연결해 둔 뒤 심사 안내 칸에 적는다.

```
이 앱은 사용자가 직접 설치한 이어온 서버에 연결해 쓰는 앱입니다. 심사용 시험 서버를 준비했습니다.
1) 서버 주소: (심사용 허브 주소)
2) 연결 코드: (심사 기간 동안 유효한 코드 — 코드는 한 번만 쓰이므로 여러 개 준비)
연결 후 "AI 직원" 목록에서 하나를 눌러 질문을 보내면 시험용 답이 옵니다.
```

- 연결 코드는 지금 10분·한 번만이라 심사에 맞지 않는다 → AP-5에서 "심사용 긴 코드"(주인이 웹에서 만들고 끌 수 있는) 또는 심사 전용 시험 허브 운영 방법을 정한다.
