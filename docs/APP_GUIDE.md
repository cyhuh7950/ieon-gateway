# 이어온 앱 따라 하기 — 설치부터 기능 확인까지

이 문서는 **이어온 앱(안드로이드·PC)과 새 웹 기능을 처음부터 끝까지 따라 하며 확인**하기 위한 설명서입니다. 순서대로 하면 되고, 각 단계 끝의 **☐ 확인**에 표시해 두었다가 마지막 [9. 결과 알려 주기](#9-결과-알려-주기)로 알려 주시면 됩니다.

- **지금 판은 0.1.6입니다**(아래 2026-11-19 갱신). 이 문서는 2026-11-14에 0.1.1(시험판) 기준으로 처음 썼고, 이후 판의 기능(작업 화면·요청 중지·재개 확인·사람에게 넘기기 카드·"바빠요" 안내·승인 카드 파일 경로·휴대폰 알림)을 반영했습니다. 지금 기준: 허브 `ieun-gateway.sinsan.kr`, 이 PC는 **허브형**(허브에 연결)으로 동작 중.
- 기능 설명만 보려면 [BEGINNER_GUIDE](BEGINNER_GUIDE.md) 9-1~9-4, 개발용 API는 [API_GUIDE](API_GUIDE.md) 7-1.
- 2026-11-19 갱신: 지금 앱은 **0.1.6**(정식 서명)이고 **허브에서 받습니다**(스토어 없음 — 1-2절). 앱을 닫아도 오는 **휴대폰 알림**(8-7절)이 됩니다. 아이폰 앱은 보류입니다.

## 1. 준비물 (시작 전에)

### 1-1. 꼭 있어야 하는 것

| 준비물 | 확인 방법 | 없으면 |
| --- | --- | --- |
| 이 PC에서 이어온이 켜져 있음 | 바탕화면 **이어온** 열기 → 대화 목록이 보임 | 이 PC 다시 시작 후 다시 열기(설명서 [BEGINNER_GUIDE](BEGINNER_GUIDE.md) 11) |
| 허브 웹 화면 로그인 | 브라우저에서 https://ieun-gateway.sinsan.kr 열기 → 로그인 | 비밀번호는 신산님이 정한 허브 관리자 비밀번호 |
| 허브에 이어 쓸 대화가 연결돼 있음 | 허브 화면 왼쪽 목록에 대화(예: Codex 시험 대화)가 보임 | [BEGINNER_GUIDE](BEGINNER_GUIDE.md) 3절로 연결 |
| AI 응답 켜짐 | 이 PC 이어온 화면 위쪽 스위치가 **AI 응답 켜짐** | 스위치를 눌러 켬 |
| 안드로이드 휴대폰 | 안드로이드 **7.0 이상**(설정 → 휴대전화 정보 → 소프트웨어 정보) | 아이폰은 아직 안 됨 |
| 휴대폰 인터넷 | 와이파이 또는 데이터 | — |
| PC 앱용 Windows | Windows 10 또는 11 | — |

### 1-2. 설치 파일 — 허브에서 받기(2026-11-18부터, 스토어 없음)

- **휴대폰:** 휴대폰 브라우저 주소창에 **`ieun-gateway.sinsan.kr/app`** → 안드로이드 앱이 바로 받아집니다.
- **PC:** 허브 웹 화면 **⚙ 설정 → 앱과 기기 → 앱 받기**의 **PC 앱** 버튼.
- 새 판이 올라오면 앱 첫 화면 위에 **"새 판 ○○이 있어요 — 받기"**가 뜹니다. 누르면 받아지고, 설치(업데이트)는 휴대폰이 물어봅니다.

> 안드로이드 앱은 0.1.6부터 **이어온 정식 서명**입니다. 0.1.5 이하(시험용 서명)가 깔려 있으면 **한 번만 지우고** 새로 설치한 뒤 연결 코드로 다시 연결하세요(안드로이드는 서명이 다른 앱 위에 덮어 설치하지 않음). PC 설치 파일은 아직 서명이 없어 처음 실행 때 Windows 경고가 뜹니다(아래).

### 1-3. 서버 주소와 연결 코드 — 앱마다 한 번

앱을 연결할 때마다 **새 연결 코드**가 필요합니다(10분 동안 한 번만 쓸 수 있음). 휴대폰용·PC 앱용을 따로 만드세요.

1. 브라우저에서 https://ieun-gateway.sinsan.kr 열기 → 로그인.
2. 왼쪽 아래 **⚙ 설정** → 위쪽 탭 **앱과 기기**.
3. **이어온 앱 연결** 칸의 **연결 코드 만들기** 누르기.
4. 화면에 **서버 주소**(`https://ieun-gateway.sinsan.kr`)와 **8자리 연결 코드**가 나옵니다 → 10분 안에 앱에 넣습니다.
5. 연결한 뒤에는 같은 칸 목록에 그 기기(예: "이어온 안드로이드")가 보입니다.

☐ 확인 1-3: 연결 코드가 8자리로 나왔다.

## 2. 안드로이드 앱 설치·연결 (A)

### 2-1. 휴대폰으로 파일 받기

- **가장 쉬운 방법:** 휴대폰 브라우저 주소창에 `ieun-gateway.sinsan.kr/app` → 받기 → 받은 파일 누르기.
- 그 밖의 방법(파일을 PC에서 옮기기):

- **카카오톡 "나와의 채팅":** PC 카카오톡에서 나와의 채팅을 열고 APK 파일을 끌어다 놓기 → 휴대폰 카카오톡에서 그 파일 누르기.
- **USB 케이블:** 휴대폰을 PC에 연결 → 휴대폰 알림에서 "파일 전송" 선택 → PC 파일 탐색기에서 휴대폰의 `Download` 폴더로 APK 복사 → 휴대폰 **내 파일** 앱 → 다운로드에서 누르기.
- **구글 드라이브:** PC에서 드라이브에 올리기 → 휴대폰 드라이브 앱에서 내려받아 누르기.

### 2-2. 설치

1. APK를 누르면 **"이 출처의 앱은 설치할 수 없어요"**류의 창이 뜹니다 → **설정** → **이 출처 허용** 켜기 → 뒤로.
   (카카오톡으로 받았으면 카카오톡, 내 파일이면 내 파일에 대해 허용을 묻습니다. 시험이 끝나면 다시 꺼도 됩니다.)
2. **설치** 누르기.
3. **Play 프로텍트** 창("알 수 없는 앱" / "앱 검사")이 뜨면 → **세부정보 더보기 → 그래도 설치**(또는 "검사 없이 설치").
4. 설치가 끝나면 **열기**. 휴대폰 홈 화면에는 청록 바탕에 흰 **"이"** 아이콘 **이어온**이 생깁니다.

☐ 확인 2-2: 앱을 열면 청록 "이" 그림이 잠깐 뜬 뒤 **이어온 연결** 화면이 나온다.

### 2-3. 연결

1. **서버 주소** 칸: `ieun-gateway.sinsan.kr` (앞의 https:// 는 빼도 됩니다).
2. **연결 코드** 칸: 1-3에서 만든 8자리.
3. (선택) **이 기기 이름**을 눌러 이름 바꾸기 — 기본 "이어온 안드로이드".
4. **연결** 누르기.

| 결과 | 뜻 |
| --- | --- |
| 첫 화면(**이어온** — 방·AI 직원 목록)이 나옴 | 성공 |
| "연결 코드가 맞지 않거나 이미 썼거나 10분이 지났어요" | 새 코드를 만들어 다시 |
| "서버에 닿지 않았어요" | 휴대폰 인터넷·서버 주소 확인 |

☐ 확인 2-3: 첫 화면에 허브에 연결된 대화(AI 직원)가 보인다. 허브 설정 → 앱과 기기 → 이어온 앱 연결 목록에 이 휴대폰이 보인다.

## 3. PC 앱 설치·연결 (B)

1. 허브 웹 화면 **⚙ 설정 → 앱과 기기 → 앱 받기**의 **PC 앱** 버튼으로 받은 설치 파일을 더블클릭.
2. 파란 **"Windows의 PC 보호"** 창이 뜨면 → **추가 정보** → **실행**.
3. 설치 마법사: 설치 폴더는 그대로(내 사용자 폴더, 관리자 권한 필요 없음) → **설치** → **마침**.
4. 바탕화면·시작 메뉴의 **이어온 앱** 열기.
   (바탕화면에 원래 있던 **이어온**은 이 PC 웹 화면 바로 가기로 따로입니다. 헷갈리지 않게 이름이 다릅니다.)
5. 1-3으로 **새 연결 코드**를 만들어 2-3처럼 연결(서버 주소 `ieun-gateway.sinsan.kr`).

☐ 확인 3: PC 앱 창(세로로 긴 창)에 휴대폰과 같은 목록이 나온다. 아래쪽에 **🔔 알림 켜짐**이 보인다.

## 4. AI 직원 목록과 1:1 대화 (C)

### 4-1. 목록 보기

첫 화면 **AI 직원** 칸에 대화마다 한 줄씩: 아이콘(없으면 이름 첫 글자), 이름, 아래 작은 글씨(역할·엔진·PC 이름), 오른쪽 **상태**.

| 상태 | 뜻 |
| --- | --- |
| 대기 | 바로 보낼 수 있음 |
| 처리 중 | 이 대화가 답하는 중 |
| PC 꺼짐 | 그 PC가 연결되지 않음 |
| 알림 N | 처리할 카드가 있음(예: AI가 꺼짐) |
| 확인 필요 | 지난 질문의 결과를 확인해야 함 |

### 4-2. 질문하기

1. 시험 대화 하나를 누르기.
2. 아래 입력칸에 짧은 질문(예: "지금 몇 시인지 말고, 안녕이라고만 답해 줘") → **보내기**.
3. "답을 기다리는 중…" → 답이 오면 말풍선으로 바뀝니다(새로 고침 필요 없음).
4. ‹ 를 눌러 목록으로 → 다시 들어가면 방금 주고받은 말이 남아 있습니다(웹에서 주고받은 기록도 함께 보임).

☐ 확인 4: 질문 → 답이 새로 고침 없이 떴다. PC 앱에서도 같은 대화에 그 기록이 보인다.

> 보낼 수 없는 상태면 입력칸에 "지금은 보낼 수 없어요"가 나오고, 위쪽에 이유 카드(예: "PC 연결이 끊겨 있어요")가 보입니다.

## 5. 허락 카드 (D) — 작업 모드를 켠 Codex·Antigravity 시험 대화에서

1. **허브 웹 화면**에서 Codex·Antigravity 시험 대화를 고르고 → 위쪽 **연결 설정** → **작업 모드 켜기** 체크.
   (작업 폴더가 정해진 대화만 켤 수 있습니다. 안 켜지면 [BEGINNER_GUIDE](BEGINNER_GUIDE.md) 5-2의 준비를 먼저.)
2. **휴대폰 앱**에서 그 대화를 열고 파일을 만드는 질문을 보냅니다. 예: "작업 폴더에 hello.txt 파일을 만들고 안에 hi라고 써 줘."
3. 잠시 뒤 대화 안에 노란 테두리 **"허락이 필요해요 — 파일 바꾸기"**(또는 "명령 실행") 카드가 뜹니다. 무엇을 하려는지·폴더·"○시 ○분까지 정하지 않으면 거부돼요"가 보입니다.
4. **허용** → 작업이 진행되고 답이 옵니다. (한 번 더 해서 **거부**도 눌러 보세요 → "실행하지 않았다"는 답.)
5. 끝나면 웹에서 **작업 모드 켜기** 체크를 다시 끕니다.

☐ 확인 5: 휴대폰에 허락 카드가 떴고, 허용/거부가 그대로 반영됐다.

## 6. 다시 보내기 (E) — 보내지 않은 게 확실할 때만

보내지 못한 질문(예: 다른 곳에서 그 대화를 쓰는 중)에만 **다시 보내기** 버튼이 한 번 나옵니다. 결과를 모르는 질문은 다시 보내지 않고 확인 카드로 정리합니다.

1. **Codex 데스크톱 앱**에서 시험 대화를 열어 둡니다(업무 대화 말고 시험 대화).
2. 휴대폰 앱에서 그 대화로 질문 → 빨간 말풍선 "Codex 앱에서 이 대화를 열고 있어 보내지 않았어요…" + **다시 보내기**.
3. Codex 데스크톱에서 그 대화를 닫고 → 휴대폰에서 **다시 보내기** → 답이 옵니다. 버튼은 한 번만 나옵니다.

☐ 확인 6: 보내지 못함 → 다시 보내기 → 답.

## 7. 방 (F) — 여러 AI 직원에게 함께

### 7-1. 방 만들기

1. 첫 화면 **방** 줄의 **+ 방 만들기**.
2. **방 이름**(예: 개발팀), **AI 직원**에서 2명 이상 체크, **대표**(아무도 안 부르면 답하는 직원) 고르기, 필요하면 **공통 안내**(이 방 질문마다 앞에 붙는 말).
3. **만들기** → 방 화면이 열립니다.

### 7-2. 방에서 묻기

1. 아래 **@이름 칩**(예: @코덱스)을 누르면 입력칸에 `@코덱스 `가 붙고, 위에 **"→ @코덱스에게 보내요"**가 보입니다. 아무도 안 부르면 "→ @대표에게 보내요".
2. 두 명을 부르고 보내면 두 직원에게 각각 갑니다. 답은 이름 아래 말풍선으로.
3. 부른 직원이 꺼져 있거나 사용 중이면 노란 **"○○ — … 보내지 않았어요"** 알림 + **○○에게 다시 보내기**(한 번).
4. 끝난 답 아래 **다른 AI 직원에게 넘기기** → 넘길 사람 고르기 → (선택) 함께 보낼 말 → **넘기기**. 그 답을 인용해 다른 직원에게 보냅니다(사람이 누를 때만).
5. 방에서 작업 모드 대화가 허락을 물으면 허락 카드가 방 안에 뜹니다.

### 7-3. 방 고치기·지우기

방 위쪽 **⚙** → 이름·직원·대표·공통 안내 바꾸고 **저장**, 맨 아래 **이 방 지우기**(방 기록만 지워지고 각 직원 대화는 그대로).

☐ 확인 7: @이름으로 부른 직원만 답했다 / 꺼진 직원은 "보내지 않았어요" 알림 / 넘기기가 됐다 / 방 지우기 뒤 1:1 대화는 그대로.

## 8. 나머지 기능 (G~J)

### 8-1. AI 직원 이름·아이콘 (G)

1. 1:1 대화 위쪽 **✎**.
2. **이름**(빈칸 없이, 방에서 @이름으로 부를 이름), **아이콘**(이모지 하나, 예: 🛠) → **저장**.
3. 위쪽·목록·방의 칩이 바로 바뀝니다. 빈칸 있는 이름은 "이름은 빈칸 없이…"로 거절됩니다. 역할은 웹 화면에서 정합니다.

☐ 확인 8-1: 이름·아이콘이 목록과 방에 반영됐다.

### 8-2. 음성 (H)

처음 쓸 때 **"음성 쓰기 전에"** 안내 창이 한 번 뜹니다 → **확인**.

| 어디서 | 🎤 말로 쓰기 | 🔈/🔊 읽어 주기 |
| --- | --- | --- |
| 휴대폰 앱 | 🎤 누르면 **구글 받아쓰기 창**이 뜸 → 말하기 → 글자가 **입력칸에 들어감**(바로 보내지 않음, 고친 뒤 보내기). 보낸 질문 위에 "🎤 음성" 표시 | 대화 위쪽 🔈 누르면 🔊(켜짐) → 새 답을 소리로 읽음. 답 아래 **🔈 읽기**로 그 답만 |
| PC 앱 | 🎤 누르면 안내: **입력칸 누르고 Windows 키 + H**(Windows 받아쓰기) | Windows 한국어 목소리로 읽음 |
| 웹 화면(크롬·엣지) | 입력칸 왼쪽 🎤 → 브라우저가 마이크 허용을 물으면 **허용** → 말하기 | 위쪽 **🔈 읽어 주기** → 켜짐 |

- 허락(승인)은 말로 하지 않습니다(카드 버튼만).
- 소리가 안 나면 기기 소리 크기, 안드로이드는 설정 → 텍스트 음성 변환에서 한국어가 있는지 확인.

☐ 확인 8-2: 휴대폰에서 말한 것이 입력칸에 글자로 들어왔다 / 새 답을 소리로 읽어 줬다.

### 8-3. 알림 (I)

알림에는 **"○○가 답했어요" / "○○가 허락을 기다려요" / "○○에게 보내지 못했어요"**만 나오고 질문·답 내용은 없습니다. 그 화면을 보고 있으면 뜨지 않습니다.

- **PC 앱:** 처음부터 켜져 있음. PC 앱을 **최소화**(또는 다른 창 보기)한 상태에서 **휴대폰으로** 질문을 보내면, 답이 올 때 화면 오른쪽 아래에 Windows 알림. 알림을 누르면 PC 앱이 앞으로 오고 그 대화가 열림.
- **웹 화면:** 허브 화면 왼쪽 아래 **🔕 알림** → 브라우저가 "알림 표시"를 물으면 **허용** → **🔔 알림 켜짐**. 다른 탭을 보는 동안 다른 기기에서 질문하면 알림.
- **휴대폰:** 앱을 닫아도 알림이 옵니다(아래 8-7 휴대폰 알림). 앱을 열어 두면 화면에 바로 보입니다.

☐ 확인 8-3: PC 앱 최소화 중 Windows 알림이 떴다 / 웹 알림이 떴다 / 알림에 내용이 없었다.

### 8-4. 지우기·끊기·처리방침 (J)

1. **대화 기록 지우기:** 1:1 대화 위쪽 ✎ → **이 대화의 서버 보관 기록 지우기** → 확인 → 그 대화 화면이 비워짐(원래 Codex·Claude 세션 기록은 그대로). 웹은 연결 설정 → 보관 기록에서 같은 버튼. **되돌릴 수 없으니 시험 대화에서만.**
2. **처리방침:** 앱 첫 화면 아래 **개인정보 처리방침** → 휴대폰 브라우저에서 열림.
3. **이 기기 연결 끊기:** 첫 화면 아래 **이 기기 연결 끊기** → 확인 → 앱이 **이어온 연결** 화면으로. 허브 설정 → 앱과 기기 → 이어온 앱 연결 목록에서 그 기기가 끊긴 것으로 보임. 다시 쓰려면 새 연결 코드.

☐ 확인 8-4: 기록 지우기·처리방침 열기·연결 끊기가 됐다.

### 8-5. 안드로이드 뒤로 가기

대화·방 화면에서 휴대폰 **뒤로** → 목록, 목록에서 **뒤로** → 앱 닫힘.

☐ 확인 8-5

### 8-6. 작업 화면

목록 위쪽 **☰ 작업** → 승인 대기(허용·거부), 진행 중·확인 필요, 최근 질문이 보입니다. 질문의 **자세히**(질문·승인 결과·답), **중지**(진행 중일 때), **대화로**를 눌러 봅니다. 질문을 보내는 중이면 답을 기다리는 동안 1:1 대화의 **중지**로도 멈출 수 있습니다.

☐ 확인 8-6: 작업 화면이 열리고, 자세히·대화로가 된다.

### 8-7. 휴대폰 알림 (안드로이드, 0.1.4부터)

앱을 닫거나 홈 화면으로 내려 둬도 "○○가 답했어요 / 허락을 기다려요 / 보내지 못했어요"가 휴대폰에 옵니다(질문·답 내용은 보내지 않음). 앱을 보고 있는 동안에는 띄우지 않습니다.

1. **한 번만(허브 관리자):** [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기 → 안드로이드 앱 추가(패키지 이름 `kr.sinsan.ieon`) → `google-services.json` 받기 → ⚙ 프로젝트 설정 → 서비스 계정 → **새 비공개 키 생성**. 두 파일을 허브 **⚙ 설정 → 앱과 기기 → 휴대폰 알림**에 올립니다(비공개 키는 다시 보이지 않음).
2. 앱을 열면 **"이어온에서 알림을 보내도록 허용할까요?"** → **허용**(안드로이드 12 이하는 묻지 않고 켜짐).
3. 알림을 누르면 그 대화가 열립니다. 끄기: 휴대폰 설정 → 알림 → 이어온, 또는 허브의 **휴대폰 알림 끄기(키 지우기)**.

☐ 확인 8-7: 앱을 내려 둔 채 질문하면 "○○가 답했어요" 알림이 오고, 누르면 그 대화가 열린다.

## 10. 시험이 끝난 뒤

| 할 일 | 방법 |
| --- | --- |
| 앱을 계속 쓸 거면 | 그대로 두면 됩니다 |
| 휴대폰 앱 지우기 | 아이콘 길게 누르기 → 제거. 그 전에 앱에서 **이 기기 연결 끊기**를 하면 서버 쪽 열쇠도 지워짐(안 했으면 허브 설정 → 앱과 기기 → 이어온 앱 연결에서 **끊기**) |
| "이 출처 허용" 되돌리기 | 휴대폰 설정 → 애플리케이션 → (카카오톡·내 파일 등) → 출처를 알 수 없는 앱 설치 → 끄기 |
| PC 앱 지우기 | Windows 설정 → 앱 → 설치된 앱 → **이어온 앱** → 제거 |
| 작업 모드 끄기 | 허브 웹 → 그 대화 연결 설정 → 작업 모드 켜기 해제 |
| 웹 알림 끄기 | 허브 화면 왼쪽 아래 **🔔 알림 켜짐** 누르기 |
| 쓰지 않은 연결 코드 | 10분 지나면 저절로 못 씀 |

## 11. 문제가 생기면

| 보이는 문구·증상 | 원인 | 할 일 |
| --- | --- | --- |
| 연결 코드가 맞지 않거나… 10분이 지났어요 | 코드 틀림·사용함·시간 지남 | 1-3으로 새 코드 |
| 서버에 닿지 않았어요 | 인터넷·주소 | 주소 `ieun-gateway.sinsan.kr` 확인, 와이파이·데이터 확인 |
| 이 기기 연결이 끊겼어요 | 웹에서 그 기기를 끊음 | 새 코드로 다시 연결 |
| PC 꺼짐 / PC 연결이 끊겨 보낼 수 없어요 | 이 PC 이어온이 허브와 끊김 | 이 PC 켜짐·인터넷 확인, 이 PC 이어온 다시 시작 |
| AI 응답이 꺼져 있어요 | 이 PC 스위치 꺼짐 | 이 PC 이어온 화면 위쪽 스위치 켜기 |
| Codex 앱에서 이 대화를 열고 있어… | 데스크톱에서 그 대화가 열림 | 닫고 **다시 보내기** |
| 결과를 확인할 수 없어요 | 보냈는지 불분명 | 그 대화의 확인 카드에서 "실행됐어요/안 됐어요" |
| 허락 카드가 안 뜸 | 작업 모드 꺼짐 / Codex·Antigravity 대화가 아님 | 5절 1번 다시 |
| 🎤가 안 보임(웹) | 브라우저가 받아쓰기 미지원(예: 파이어폭스) | 크롬·엣지 또는 Windows 키 + H |
| 소리가 안 남 | 소리 크기·한국어 음성 없음 | 8-2 아래 안내 |
| Windows 알림이 안 뜸 | PC 앱을 보고 있음 / 알림 꺼짐 / Windows 방해 금지 | 최소화한 채 시험, 첫 화면 🔔 확인, Windows 설정 → 시스템 → 알림에서 **이어온 앱** 켜기 |
| 웹 알림이 안 뜸 | 브라우저에서 알림을 막음 | 주소창 왼쪽 자물쇠 → 알림 → 허용 |
| 설치 때 "앱이 설치되지 않았습니다" | 같은 이름의 다른 서명 앱이 있음 | 기존 이어온 앱을 지우고 다시 설치 |
