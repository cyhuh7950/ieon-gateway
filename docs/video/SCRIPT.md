## 01 웹 화면에서 질문하기

| # | 화면 | 말(자막) |
| --- | --- | --- |
| 1 | 표지 "01 웹 화면에서 질문하기" | 웹 화면에서 질문하는 방법입니다. |
| 2 | 웹 화면 전체 — 왼쪽 목록 | 왼쪽에는 이어 쓸 작업 세션, 즉 AI 직원 목록이 있습니다. 오른쪽 표시로 지금 상태를 알 수 있습니다. |
| 3 | 대화 하나 고르기 | 하나를 고르면 그 세션과 주고받은 말이 보입니다. |
| 4 | 질문 쓰고 보내기 | 아래 입력칸에 질문을 쓰고 보내기를 누릅니다. |
| 5 | 접수 → 실행 중 → 답 | 접수, 실행 중을 거쳐, PC의 작업 세션이 답하면 여기에 바로 나타납니다. |
| 6 | 꺼진 대화의 카드 | 보낼 수 없는 상태면, 이렇게 이유를 알려 주는 카드가 먼저 뜹니다. |
| 7 | 연결 설정 패널 | 연결 설정에서는 엔진과 상태, 이어 쓰는 방법을 확인할 수 있습니다. |
| 8 | 끝 | 다음 영상에서는 AI 직원과 방을 알아보겠습니다. |

## 02 AI 직원과 방

| # | 화면 | 말(자막) |
| --- | --- | --- |
| 1 | 표지 "02 AI 직원과 방" | AI 직원과 방을 쓰는 방법입니다. |
| 2 | 연결 설정 → AI 직원 이름·아이콘 | 연결 설정의 AI 직원 칸에서 이름과 아이콘을 정합니다. 방에서는 이 이름으로 부릅니다. |
| 3 | 방 만들기 창 | 방 만들기를 누르고, 이름과 구성원, 대표를 고릅니다. 대표는 아무도 부르지 않았을 때 답하는 직원입니다. |
| 4 | @이름으로 두 명 부르기 | 골뱅이 이름으로 부르면, 부른 직원에게만 질문이 갑니다. |
| 5 | 두 직원의 답 | 각 직원의 답이 이름 아래에 나타납니다. |
| 6 | 넘기기 | 끝난 답은 다른 직원에게 넘겨, 이어서 일하게 할 수 있습니다. 넘기기는 사람이 누를 때만 일어납니다. |
| 7 | 끝 | 다음 영상에서는 허락 카드를 알아보겠습니다. |

## 03 허락 카드 — 일 맡기기

| # | 화면 | 말(자막) |
| --- | --- | --- |
| 1 | 표지 "03 허락 카드" | AI에게 실제 작업을 맡기는 방법입니다. |
| 2 | 연결 설정 → 작업 모드 켜기 | 연결 설정에서 작업 모드를 켜면, 그 대화의 AI가 파일을 고치거나 명령을 실행할 수 있게 됩니다. 기본은 꺼져 있습니다. |
| 3 | 작업 질문 보내기 | 작업을 부탁하면, |
| 4 | 허락 카드 | 실행하기 전에 무엇을 하려는지 보여 주는 허락 카드가 뜹니다. |
| 5 | 허용 → 답 | 허용을 누르면 그 한 번만 실행하고 결과를 알려 줍니다. 십오 분 안에 정하지 않으면 거부됩니다. |
| 6 | 끝 | 다음 영상에서는 휴대폰 앱을 연결해 보겠습니다. |

## 04 휴대폰 앱 연결하기

| # | 화면 | 말(자막) |
| --- | --- | --- |
| 1 | 표지 "04 휴대폰 앱 연결하기" | 이어온 앱을 휴대폰에 연결하는 방법입니다. |
| 2 | 웹 설정 → 내 프로그램 연결 → 연결 코드 만들기 | 웹 화면의 설정에서 내 프로그램 연결을 열고, 연결 코드 만들기를 누릅니다. 서버 주소와 여덟 자리 코드가 나옵니다. |
| 3 | 휴대폰: 이어온 연결 화면 | 휴대폰 앱에 서버 주소와 코드를 넣고 연결을 누릅니다. 코드는 십 분 동안 한 번만 쓸 수 있습니다. |
| 4 | 휴대폰: 목록 | 웹 화면과 같은 AI 직원과 방이 보입니다. |
| 5 | 휴대폰: 질문과 답 | 질문을 보내면, 답이 오는 대로 바로 나타납니다. |
| 6 | 휴대폰: 허락 카드 | 허락 카드도 휴대폰에서 바로 허용하거나 거부할 수 있습니다. |
| 7 | 끝 | 다음 영상에서는 음성과 알림을 알아보겠습니다. |

## 05 음성·알림·지우기

| # | 화면 | 말(자막) |
| --- | --- | --- |
| 1 | 표지 "05 음성·알림·지우기" | 음성과 알림, 그리고 지우는 방법입니다. |

| 4 | 휴대폰: 읽어 주기 켜기 | 스피커를 켜 두면 새 답을 소리로 읽어 줍니다. |
| 5 | PC 앱 + Windows 알림 | PC 앱을 최소화해 두면, 답이 왔을 때 알림이 뜹니다. 알림에는 내용 없이, 누가 답했는지만 나옵니다. |
| 6 | 휴대폰: 기록 지우기·연결 끊기 | 대화의 서버 기록 지우기와, 이 기기 연결 끊기도 앱에서 바로 할 수 있습니다. |
