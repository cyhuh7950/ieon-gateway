# 웹 중심 재설계: 설정은 웹에서, 토큰은 내부에서

기준: 2026-11-08. 상태: **설계 초안(신산님 확인 전), 코드 변경 없음.**

## 0. 원칙 (신산님 2026-11-08, 최우선)

1. **가능한 모든 설정은 웹 화면에서 한다.** 사용자가 명령 프롬프트(PowerShell·SSH·nano·cat)에서 하는 일을 최소화한다.
2. **토큰은 내부에서 처리한다.** 사용자에게 토큰을 만들게 하거나, 파일에 넣게 하거나, 복사해 붙이게 하지 않는다.
3. 외부 서비스가 발급한 값(텔레그램·디스코드·슬랙 봇 토큰)만 웹에 **입력**받고 다시 보여 주지 않는다(있음/없음).
4. 외부 화면에 붙여야 하는 값(카카오 스킬 URL)은 웹의 **복사 버튼**으로 준다.
5. 서버(Oracle) 파일은 `ubuntu@sinsan-server:~/deploy/ieon-gateway` 아래에만 두고 Docker로 실행한다(별도 OS 사용자 `ieon` 배치는 폐기).
6. 기존 안전 원칙은 유지한다: PC의 안전 설정(연결부 허용 목록·실제 실행·작업 폴더·`full`)은 **그 PC의 로컬 웹에서만** 바꾸고 허브 웹에서는 못 바꾼다. 업무 대화 제외, 자동 재전송 없음, 로그에 토큰·질문·답 원문 없음.

## 2. 로그인과 내부 토큰

- 웹 로그인은 쿠키(HttpOnly·Secure(https일 때)·SameSite=Strict, 12시간)로 바꾸고, 변경 요청은 `Origin` 검사로 CSRF를 막는다. 비밀번호는 scrypt 해시, 5회 실패 시 15분 잠금, 로그인·실패는 시각·주소만 기록.
- 허브 첫 설정: 관리자가 없을 때만 "관리자 만들기" 화면을 보이고, 그 요청도 접속 제한(5-1)을 통과해야 한다.
- PC 로컬 웹 자동 로그인: 설치·자동 시작이 만든 **일회용 로그인 링크**(1분 유효, 1회)를 브라우저로 연다. 127.0.0.1 밖에서는 쓸 수 없다. 브라우저를 닫은 뒤에는 작업 표시줄 아이콘(또는 바로 가기)이 새 링크를 만든다.
- 외부 개발 프로그램용 API 키(API_GUIDE)는 웹에서 이름을 붙여 **발급·폐기**한다(원문은 발급 때 한 번만 보여 줌. 사용자가 만든 프로그램에 넣는 값이라 예외로 둔다).
- 메신저·연결부·중계가 서로 쓰는 토큰은 설치·짝맺기 때 자동 생성되고, 서버에는 해시만 둔다.

## 3. 짝맺기(PC ↔ 허브, PC ↔ 공개 중계)

1. PC 로컬 웹에서 상대 주소를 입력하면 PC가 상대에 `POST /v1/pair`(기기 이름, PC가 만든 공개 식별자)를 보내고, 상대는 **6자리 확인 코드**와 짝맺기 ID를 돌려준다(10분 유효, 1회).
2. PC 웹과 상대 웹(허브 기기 화면, 또는 중계 관리 화면)에 같은 코드가 보인다. 신산님이 상대 웹에서 코드를 확인하고 "승인".
3. PC가 짝맺기 ID로 상대를 조회해 **승인되면 기기 토큰을 한 번 받는다**(상대에는 해시만). PC는 토큰을 `.local`에 저장하고 연결부를 그 상대로 자동 시작한다.
4. 폐기·재발급은 상대 웹의 기기 화면(P1-c), PC 쪽은 "연결 끊기"·"다시 연결" 버튼.
- PC 완결형 공개 중계(`ieon-relay`)도 같은 짝맺기를 쓰도록, 중계에 접속 제한 뒤의 작은 관리 화면(짝맺기 승인·스킬 URL 복사)을 둔다.

## 5-2. W1 구현 (2026-11-08, 저장소 코드)

- `src/pilot/web-auth.mjs`: `/v1/auth/state`(mode·setupRequired·loggedIn·localAuto)·`/v1/auth/local`(PC, 이 PC의 127.0.0.1 직접 접속만)·`/v1/auth/setup`(관리자가 없을 때 한 번, PC는 이 PC에서만, 허브는 접속 제한 통과한 곳)·`/v1/auth/login`(5회 실패 15분 잠금, 429)·`/v1/auth/logout`·`/v1/auth/password`(바꾸면 다른 로그인 모두 끊김). 모든 POST는 Origin 검사.
- 쿠키 `ieon_sid`(HttpOnly·SameSite=Strict·12시간, `X-Forwarded-Proto: https`면 Secure), DB `web_sessions`에 해시만. 관리자 비밀번호는 설정 `auth.admin`(scrypt). 로그인·실패는 시각·주소만 로그.
